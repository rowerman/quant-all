# V1：回测项目构成与流程文档

## 需求拆分

- V1-1：静态梳理 `backtest/` 的入口、配置、数据、信号、订单、执行、指标、存储和测试模块。
- V1-2：确认 `quant` 数据读取层与 `calculate.universe` 股票池定义在本项目中的边界。
- V1-3：还原 `__main__ -> pipeline -> data -> engine -> orders/metrics -> store` 调用链。
- V1-4：说明前复权价格、严格基准对齐、指数上月快照、上市 60 日、停牌/涨跌停、退市强平、100 股取整和交易成本口径。
- V1-5：说明策略版本、运行状态、结果表和日志/异常机制。
- V1-6：形成根目录总文档，并同步形成 `docs/project-learning/` 分层文档。

## 完成标准

- 根目录存在项目总说明 Markdown；
- 每个源码文件和测试文件均在文档中有定位；
- 关键函数有签名、输入、输出、核心分支和边界说明；
- 回测流程按实际执行顺序描述，并标明代码位置；
- 不覆盖用户已有业务改动。
