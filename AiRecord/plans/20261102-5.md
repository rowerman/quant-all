# 20261102-5 P3-05 自由探索端到端与防泄漏验收

## 目标

完成 `FACTOR_MINING_PROGRESS.md` 的 P3-05：验证无初始假设的自由探索运行可从 V2
Web/API 进入搜索，完成开发期、选择期、最终研究和一次性测试段后进入 `review_ready`，
并覆盖取消、恢复、冻结方向和跨窗口防泄漏边界。

## 范围

- 使用真实 `MiningSearchOrchestrator` 和确定性假 Worker/评估器完成联合测试。
- 验证无初始假设创建、种子冻结、方向规划、候选评估和审核准备态。
- 验证 Worker 前取消不会调用 Worker。
- 验证中断恢复复用已完成轮次和方向计划，不重复调用已完成付费步骤。
- 递归检查 Worker 请求、公开详情和事件，选择期、最终研究期、测试段、Prompt 和密钥
  不出现在 Agent 可见面。
- 不修改数据库 schema、不迁移旧运行、不调用真实付费 Worker、不发布正式因子。

## 测试设计

1. 通过 `MiningSearchWebService.create_run()` 提交自由探索请求。
2. 用确定性 Worker 返回分支和停止建议，以现有评估器构造有效开发、选择、完整和
   测试段证据。
3. 运行结束后断言 `review_ready`、候选可审批准备、方向与有效种子稳定。
4. 在独立运行中先取消再执行，断言状态为 `cancelled` 且 Worker 请求为空。
5. 在第二个 Worker 轮次前中断，登记 `interrupted` 后恢复，断言只调用剩余轮次并得到
   相同方向和最终状态。
6. 对所有 Worker 请求执行递归禁字段检查，并核对公开详情不含 Prompt、API Key、
   工作区路径和隐藏窗口日期。

## 验收

- 无初始假设可进入搜索并到达 `review_ready`。
- 选择期、最终研究期和模块测试段不进入任何 Agent 请求或公开详情。
- 取消和恢复边界稳定，不重复执行已完成 Worker 作业。
- 页面浏览器验收继续通过，方向/预算/停止原因和 390px 布局无回归。
