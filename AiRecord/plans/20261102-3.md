# 20261102-3 P3-03 自由探索方向池与停止控制

## 目标

完成 `FACTOR_MINING_PROGRESS.md` 的 P3-03：在 P3-02 首轮方向之上增加方向多样性、
结构化语义去重、连续无改善停止、冻结预算控制和可恢复的分支规划。

## 范围

- 为 `ResearchDirection` 增加结构化语义哈希。
- 新增冻结方向池和确定性的下一分支方向规划。
- 自由探索分支由主服务规划方向，Worker 只负责该方向内的候选生成。
- 重复方向记录尝试但不创建新假设、批次或候选。
- 修订轮继承当前方向和最大表达式深度。
- 复用现有搜索预算和控制器，不扩大轮次、分支或候选上限。
- 不实现 P3-04 的 Web/API 模式入口，也不实现 P3-05 的完整端到端页面验收。

## 接口设计

1. 方向语义指纹只包含机制类别、排序后的数据依赖、预期方向和表达复杂度，不包含
   措辞、随机种子或内容哈希。
2. 方向池枚举冻结目录支持的机制、字段和复杂度组合，优先选择尚未使用的机制类别。
3. `plan_next_branch_direction()` 返回选中方向、跳过的重复方向、方向池版本和稳定
   计划哈希；同一请求、上下文及历史假设必须得到相同结果。
4. 分支方向通过假设 metadata 和 `free_exploration_direction_planned` 事件持久化。
5. 恢复时从已有方向和冻结种子重建同一分支计划，不重复创建假设或候选。
6. 手工假设路径、P3-02 已保存方向和现有 Worker 协议保持兼容。

## 实施步骤

1. 扩展方向契约和公共导出。
2. 新增方向池、语义判重和下一分支规划。
3. 修改逐轮编排，接入分支方向规划、修订继承和中断恢复。
4. 增加契约、方向池、编排、预算、恢复和兼容测试。
5. 更新挖掘文档、根进度、版本、变更和差异记录。
6. 运行定向与挖掘回归测试，检查编译和差异，只提交本轮文件。

## 验收

- 相同输入产生相同方向计划，机制类别在预算允许范围内保持多样。
- 重复方向计入 `duplicate` 尝试，但不创建新假设、实验批次或候选。
- 连续无改善和轮次、分支预算耗尽后确定性停止或入围，不追加 Worker 调用。
- 决策后中断可恢复同一分支方向，不重复计数或物化。
- 自由探索修订轮保持原方向和最大表达式深度。
- 选择期、最终研究期和测试段不进入方向规划或 Worker 请求。
