# V128-1 实施计划：新增挖掘 V2 搜索领域契约

## 任务信息

- 日期：2026-10-29
- 版本：V128
- 任务：P1.1 定义搜索领域契约
- 类型：feat

## 目标

在保留 `mining_v1` 契约和运行链不变的前提下，新增搜索预算、假设卡、实验批次、
开发期证据、搜索决策和尝试记录契约。所有契约必须严格解析、限制字段规模，并生成
与时间字段无关的稳定哈希和 ID。

## 实施范围

1. 新增 `mining_v2` 契约常量和严格 JSON 解析工具。
2. 定义 `SearchBudget`、`TrialCounts`、`HypothesisCard`、`ExperimentBatch`、
   `EvidencePacket`、`SearchDecision` 和 `TrialRecord`。
3. `SearchDecision` 动作只允许 `refine / branch / stop / promote`。
4. 补充缺失字段、未知字段、超限、非法动作和哈希稳定性测试。
5. 导出新公共类型，更新挖掘契约文档和 V128 进度。

## 验证

- 新增契约定向测试。
- 现有挖掘契约、状态、存储、Worker 协议、编排、评估契约和监测站 API 回归测试。
- `git diff --check`。

## 边界

- 不修改现有 `FrozenContext`、V1 存储 schema、编排流程或候选哈希。
- 不接入 Worker V2，不执行真实数据评估。
