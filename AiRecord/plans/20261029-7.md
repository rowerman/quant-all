# V129-1 实施计划：Worker v2 协议

## 任务信息

- 日期：2026-10-29
- 版本：V129
- 任务：P2.1 设计 Worker v2 协议
- 类型：feat

## 目标

新增与 V1 并存的 `mining_worker_v2` 请求、响应和 HTTP 作业入口，支持开发期证据反馈、
当前假设、候选谱系、允许动作和下一假设建议。Worker 仍只返回未信任表达式草稿，主服务
负责重新校验和计算候选身份。

## 实施范围

1. 定义严格版本化请求、决策建议、下一假设和候选草稿契约。
2. 拒绝未知字段、超量内容、非法动作和选择期/最终研究期/测试段字段。
3. 增加 Worker `/v2/jobs` 入口和独立搜索生成器。
4. 增加主服务 V2 Worker 客户端及候选规范化入口。
5. 覆盖协议、HTTP、幂等、取消、脱敏和主服务二次校验测试。

## 验证

- Worker v2 与 V1 协议联合测试。
- Worker HTTP 服务 v2 作业测试。
- 主服务候选规范化测试。
- `compileall` 和 `git diff --check`。

## 边界

- 不实现逐轮编排、控制器、恢复或页面。
- 不调用外部模型，不修改正式候选库。
