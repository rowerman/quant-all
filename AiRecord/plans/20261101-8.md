# 20261101-8 计划：建立沙箱代码确定性评估器

- 日期：2026-11-01
- 版本：V143
- 类型：feat
- 进度任务：P1-02

## 目标

为 M5 代码研究循环增加执行前代码限制检查和执行后因子明细确定性评估。评估器要校验
可执行性、输出结构、冻结交易日和股票索引、覆盖率、非有限值以及代码限制，并让相同
输入得到相同结论和反馈哈希。

## 实现

- 新增 `mining_sandbox.evaluator`，定义代码限制策略、静态检查、指标严格解析、
  因子明细校验和确定性评估结果。
- 提案输出新增 `/workspace/factor.parquet`，固定列为 `date`、`instrument`、`value`；
  缺少值以省略行表示，接收行必须属于冻结日历和股票有效区间，主键不可重复，数值必须有限。
- 以冻结快照 `row_count` 重新计算覆盖率和有效交易日，并与 `metrics.json` 核对。
- 每轮代码在进入 Docker 前完成编译和静态代码限制检查。违规代码返回 `MINING-144`，
  不启动容器；超时、OOM 和输出截断返回 `MINING-145`，其他非零退出保持 `MINING-139`。
- 成功评估写入 `evaluation.json` 并进入尝试记录；旧运行记录不需要迁移。
- Worker 代码提示升级到 `mining_qlib_code_prompt_v2`，要求同一脚本写出因子明细和指标。

## 接口

- 新增 `SandboxProposalPolicy`、`SandboxFactorEvaluation`、
  `validate_proposal_code()`、`read_research_metrics()` 和 `evaluate_factor_output()`。
- 沙箱尝试新增 `evaluation`、`evaluation_file` 和可选 `factor_file`；既有字段保持兼容。
- 不修改 V1/V2 状态机、审批发布接口、数据库结构或正式因子目录。

## 测试

- 覆盖合法因子、字段和类型错误、重复键、冻结索引外日期、股票区间外日期、
  覆盖率不一致、空输出、NaN/Inf 以及相同输入稳定哈希。
- 覆盖允许的 Qlib/NumPy/Pandas 代码，以及网络、shell、路径、动态执行、动态导入和
  环境变量等限制。
- 覆盖代码限制预检、执行错误、超时、OOM、截断、恢复和真实断网只读容器。
- 运行定向 pytest、`compileall` 和 `git diff --check`。
