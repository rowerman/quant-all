# 20261101-15 计划：研报因子草稿筛选与受控 DSL 转换

- 日期：2026-11-01
- 版本：V150
- 类型：feat
- 进度任务：P2-04

## 目标

在 P2-03 的可追溯研报字段草稿之上，完成六字段证据、研报内部一致性、方向、字段可用性
和重复度筛选，并使用 Worker v6 的模型辅助映射转换为未落库的 `HypothesisCard` 和受控
DSL 候选草稿。

## 实现

- 定义转换上下文、资源上限、筛选结论、转换结果和稳定哈希。
- 六类字段全部非 `missing`，且只允许 `positive/negative` 方向进入模型转换。
- 按研报将最多 8 个草稿组成一个 Worker v6 作业，超出时继续分块，不静默截断。
- 模型只返回表达式和研报变量到冻结字段的映射；主服务重新校验 DSL、排除字段、
  映射键、映射值和表达式依赖。
- 通过项生成确定性 `HypothesisCard` 和 `CandidateDefinition`，跨报告按候选语义哈希
  去重；通过、拒绝、非法和重复草稿都生成 `TrialRecord` 形态的尝试记录。
- 增加 Worker v6 HTTP 路由、固定提示、独立子进程、客户端轮询、取消和超时。
- 新增 `MINING-156`～`MINING-158`，日志只记录数量、原因、模型、版本和耗时。

## 验证

- 覆盖六字段缺失、方向不支持、敏感证据、目录字段、排除字段、伪造映射和非法 DSL。
- 覆盖 Worker 请求响应绑定、8 项分块、跨报告去重、稳定哈希和尝试台账一一对应。
- 覆盖 v6 鉴权、幂等、严格协议、提示注入隔离、超时、取消和 HTTP 客户端。
- 运行资料、搜索、Worker、日志和错误映射定向回归，并执行编译与差异检查。

## 边界

- 不实现 P2-05 的运行入口、V2 台账持久化、来源展示和端到端审批发布。
- 不修改数据库 schema、状态机、Web 页面、审批或正式因子目录。
- 不调用真实付费 Worker，不提交用户既有的 `TODO_docs/` 文件迁移。
