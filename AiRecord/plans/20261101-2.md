# 20261101-2 计划：冻结 V2 到 V1 发布桥接契约

- 日期：2026-11-01
- 版本：V137
- 类型：feat
- 进度任务：P0-01

## 目标

定义 V2 搜索运行进入现有 V1 审批与发布链路前的只读兼容映射，冻结候选、冻结上下文、
分阶段证据和发布输入的复用、转换与禁止边界。本轮不实现审批、发布适配或页面入口。

## 实现

1. 新增只读 `mining.search_publication_contracts`，提供证据引用、候选桥接视图、
   发布输入和加载函数。
2. 映射前校验 V2 轨迹、候选定义、内容哈希、语义哈希、候选 ID 和评估证据身份。
3. 从 V2 最终研究窗口和持有窗口构造仅供发布构建器临时使用的 V1 `FrozenContext`，
   不持久化该派生上下文，也不把它作为 V2 上下文事实。
4. 新增接口表，明确复用、转换和禁止字段；注册到挖掘文档入口。
5. 更新根进度记录、V137 进度记录和版本记录。

## 验收

1. 同一 V2 输入重复加载得到相同候选、证据和哈希。
2. 候选定义或评估证据被篡改时，加载明确失败。
3. 非 `review_ready` 候选不能进入发布输入。
4. 桥接操作不新增事件或轨迹，V1 运行和候选保持可读。
5. 定向单元测试、相关 V2 测试、项目布局测试与 `git diff --check` 通过。

## 边界

- 不修改 V1/V2 状态机、`MiningPublicationService`、Web API、前端或数据库 schema。
- 不复制 V2 候选、审批或发布行到 V1。
- 不调用付费 Worker，不执行真实搜索、正式发布或数据迁移。
