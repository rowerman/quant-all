# 20261101-16 计划：资料驱动运行入口与 V2 闭环

- 日期：2026-11-01
- 版本：V151
- 类型：feat
- 进度任务：P2-05

## 目标

在 P2-04 已完成的研报解析、字段抽取、受控转换和语义去重之上，增加服务端资料驱动
运行入口，把转换通过的候选接入现有 V2 验证、审批和发布链路，并展示可审计来源。

## 实现

- 固定 `data/source/reports` 为资料根目录，新增只接受根目录内相对文件或目录的运行请求。
- 定义资料运行输入、候选来源和运行摘要契约，保存资料指纹、页内引用、字段映射、模型
  与提示版本，不保存整份报告正文。
- 新增 V2 资料运行和候选来源表，旧库启动时自动补表；来源哈希写入候选参数并进入候选
  内容哈希、审批资格和发布加载校验。
- 转换通过项按稳定顺序自动准入至运行候选预算；超出预算的通过项保留显式拒绝尝试。
- 资料候选作为 V2 种子批次进入开发期、选择期、完整评估和一次性测试段，随后沿用现有
  人工审批和整批原子发布；普通搜索 Worker 的每轮 4 候选限制不变。
- 新增研究运行 API、页面模式选择、运行摘要和候选来源展示；日志只记录脱敏元数据。
- 使用临时真实 PDF 和固定假 Worker 完成端到端、安全、恢复、审批和发布验收。

## 验证

- 资料契约、路径安全、预算准入、来源篡改和旧库补表单元测试。
- 资料驱动 V2 编排、隔离窗口、恢复、审批和发布联合测试。
- Web API、页面来源展示、390px 移动端、编译检查和差异检查。
- 只运行与修改直接相关的定向回归，不重复已知与本轮无关的全量挖掘失败。

## 边界

- 不实现浏览器上传、OCR、自由探索或 V3 统一来源模型。
- 自动化验收不调用真实付费 Worker，不修改正式因子目录。
- 工作区已有的 `TODO_docs/` 文件迁移不纳入本次提交。
