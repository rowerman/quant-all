# V130-5 实施计划：多重检验诊断

## 任务信息

- 日期：2026-10-29
- 版本：V130
- 任务：P4.8 生成多重检验诊断
- 类型：feat

## 目标

对进入选择期评估的候选逐日 RankIC 执行 Newey-West HAC 检验，并以包含失败和稳定性
变体的搜索规模计算 BH q-value；报告只供审核，不自动改写候选状态。

## 实施范围

1. 在选择期诊断中保存逐日 RankIC 日期和数值。
2. 定义版本化 Newey-West、BH 和运行级统计报告契约。
3. Bartlett 核带宽使用 `floor(4 * (n / 100) ** (2 / 9))`。
4. 少于 20 个有效交易日标记不可计算。
5. BH 分母取主候选尝试数、稳定性变体数和有效检验数的保守上界。
6. 将运行报告写入候选 `multiple_testing` 证据并暴露到评分卡。
7. 覆盖手算 HAC、BH、样本不足、分母和状态不变。

## 验证

- 统计诊断单元测试。
- 搜索编排、评分卡和 API 定向测试。
- `compileall` 和 `git diff --check`。

## 边界

- q-value 不参与 Pareto 排序、审批或发布。
- 报告固定提示搜索规模和选择偏差。
