# V130-2 实施计划：邻域和消融稳定性

## 任务信息

- 日期：2026-10-29
- 版本：V130
- 任务：P4.5 增加邻域和消融稳定性
- 类型：feat

## 目标

为每个通过开发期筛选的候选确定性地生成一个主整数窗口的左右相邻版本，只在开发期
评估并生成稳定、脆弱或不可判定结论；结果可恢复复用，不反馈给 Worker。

## 实施范围

1. 定义版本化稳定性报告和变体观测契约。
2. 从受控 AST 选择第一个可调整整数窗口，生成最多两个合法相邻变体。
3. 使用现有开发期评估器和隔离目录执行技术门禁与快速评估。
4. 记录方向一致性、变体 `|RankIC|` 中位数、相对基础和评估失败。
5. 将报告登记为 `stability` 评估证据，评分卡和选择期诊断可读取。
6. 覆盖窗口边界、确定性、变体上限、方向规则、失败隔离和恢复复用。

## 验证

- 稳定性契约与生成单元测试。
- 搜索编排、评分卡和监测站 API 定向测试。
- `compileall` 和 `git diff --check`。

## 边界

- 只使用开发期窗口。
- 每基础候选最多两个变体。
- 不把变体加入假设树或 Worker 下一轮候选。
