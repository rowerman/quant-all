# V130-1 实施计划：选择期相关性与增量价值

## 任务信息

- 日期：2026-10-29
- 版本：V130
- 任务：P4.4 增加增量价值和相关性
- 类型：feat

## 目标

在选择期计算同批候选相关性、相关簇、与正式因子的相关性和风格残差增量价值，
全部结果进入 V2 评估证据和候选评分卡；选择期信息不反馈给 Worker。

## 实施范围

1. 新增版本化的候选相关性、增量价值和综合诊断契约。
2. 使用确定性采样交易日和目标候选的隔离因子产物计算同批相关性。
3. 按绝对相关度 `>= 0.90` 构建稳定相关簇。
4. 复用正式因子技术门禁结果，并计算选择面板上的残差 RankIC。
5. 将诊断写入 `selection_diagnostics` 阶段，扩展评分卡和恢复读取。
6. 覆盖行集错位、缺失、常数截面、样本不足、正式因子为空和哈希稳定性。

## 验证

- 新诊断模块单元测试。
- 评分卡、V2 搜索编排和监测站挖掘 API 定向测试。
- `compileall` 和 `git diff --check`。

## 边界

- 不修改 Worker v2 协议和可见证据。
- 不读取最终研究期或模块测试段。
- 不自动审批、发布或改写候选状态。
