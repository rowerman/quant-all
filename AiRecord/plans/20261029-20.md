# V131 实施计划：M4 受控分析工具基础

## 任务信息

- 日期：2026-10-29
- 版本：V131
- 任务：P3.1 定义只读工具目录、P3.2 实现主服务查询网关、P3.3 增加工具预算和缓存
- 类型：feat

## 目标

让搜索 Worker 只能通过固定白名单工具获取当前运行开发期的补充证据。工具请求由主服务
校验和执行，Worker 只接收脱敏摘要；工具调用受每轮预算、超时、输出大小和运行内缓存
限制。

## 实施范围

1. 定义七类工具：字段查询、算子查询、当前运行实验摘要、候选证据、相关性、消融和
   参数邻域。
2. 为工具建立严格版本、参数、输出上限、稳定哈希和错误码。
3. 新增 Worker v3 工具补充协议，保留 Worker v2 兼容读取。
4. 实现主服务工具网关，所有分析固定在冻结开发期，不接收 SQL、路径、表名或代码。
5. 在 `mining_v2` 中增量增加工具调用审计和缓存表，缓存不得跨运行。
6. 每轮最多 4 次工具调用，缓存命中仍计数；单次输出不超过 64 KiB，默认超时 5 秒。
7. 增加契约、网关、预算、缓存、上下文漂移和 Worker 补充轮测试。

## 验证

- 新增工具契约、网关和存储定向测试。
- 现有搜索契约、Worker、编排、存储和监测站 API 相关测试。
- `compileall` 与 `git diff --check`。

## 边界

- 不开放任意查询、代码执行或非开发期证据。
- 不修改现有 V1 生产编排、人工审批和正式发布链路。
- 保留用户已有的操作符 Tracker 文件迁移，不纳入提交。
