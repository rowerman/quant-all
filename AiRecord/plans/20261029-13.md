# V129-7 实施计划：V2 页面与 API

## 任务信息

- 日期：2026-10-29
- 版本：V129
- 任务：P1.5 展示假设树和搜索进度
- 类型：feat

## 目标

通过 `MINING_SEARCH_V2_ENABLED` 显式开启 V2 实验链路。关闭时 V1 行为和页面保持
不变；开启后新运行走 V2，已有 V1 运行仍按 ID 正常查询、取消和恢复。

## 实施范围

1. 新增 V2 Web 用例服务，提供选项、创建、列表、详情、事件、取消、恢复和评分卡。
2. 在现有 `/api/mining/*` 路由中按开关和运行 ID 分流，合并运行列表。
3. 页面显示假设树、候选父子关系、turn 决策、预算、停止原因和尝试统计。
4. V2 页面不展示原始 Prompt、表达式正文、密钥、行情或堆栈，不开放审批和发布。
5. 覆盖 V1/V2 分流、V2 详情脱敏、SSE 终止状态和 API 回归。

## 验证
