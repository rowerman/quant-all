# V129-6 实施计划：统一候选评分卡

## 任务信息

- 日期：2026-10-29
- 版本：V129
- 任务：提前实施 P4.3 建立统一候选评分卡
- 类型：feat

## 目标

从 V2 已登记评估证据生成统一候选评分卡，包含核心研究指标、门禁、失败原因、窗口、
样本量、有效日数和尝试计数；缺失字段明确为空，不按零处理。

## 实施范围

1. 定义不可变 `CandidateScoreCard` 和固定指标集合。
2. 从技术、开发、选择、完整和测试段证据提取评分。
3. 记录运行级与候选级尝试计数并生成稳定哈希。
4. 提供单候选和运行内批量构建入口。
5. 覆盖缺失字段、证据变化、稳定哈希和无效证据测试。

## 验证

- 评分卡和 V2 证据存储联合测试。
- `compileall` 和 `git diff --check`。

## 边界

- 评分卡不自动批准、发布或改写候选状态。
