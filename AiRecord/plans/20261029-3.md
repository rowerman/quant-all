# V128-3 实施计划：建立 V2 存储和显式 V1 迁移

## 任务信息

- 日期：2026-10-29
- 版本：V128
- 任务：P1.2 设计 `mining_v2` 持久化与迁移
- 类型：feat

## 目标

在同一候选 DuckDB 中建立独立 `mining_v2` schema，提供 V2 运行和上下文读写入口；
现有 `mining_v1` schema 保持原样。V1 迁移必须显式执行、事务回滚、重复调用幂等。

## 实施范围

1. 增加 V2 表、主键、外键、唯一约束和索引。
2. 增加 `SearchRunRequest` 和 `MiningV2Store` 的运行与上下文入口。
3. 增加 V1 运行、上下文和候选只读快照及查询接口。
4. 增加显式迁移 API 和命令行入口。
5. 覆盖成功、回滚、重复、未知版本、活动运行和源快照变化测试。

## 验证

- V2 存储和迁移定向测试。
- V1 存储、契约和项目布局回归测试。
- `git diff --check`。

## 边界

- 不修改 `mining_v1` 表和现有 `MiningStore` 行为。
- V2 存储尚未接入编排器；本阶段不写入生产候选库。
