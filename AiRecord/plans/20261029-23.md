# V134 实施计划：M5 代码研究闭环与人工提升

## 任务信息

- 日期：2026-10-29
- 版本：V134
- 任务：P5.4 接入 RD-Agent Qlib/CoSTEER 研究循环、P5.5 隔离产物清单、
  P5.6 人工提升流程、P5.7 沙箱安全与恢复验收
- 类型：feat/test

## 目标

由主服务协调 RD-Agent 生成 Qlib 代码提案，沙箱无网络执行并反馈指标，最多进行有限轮次。
全部尝试、代码、日志、指标、环境和错误写入可验证的只读清单；人工提升只生成审计记录，
不自动进入正式候选或发布链路。

## 实施范围

1. 定义 `mining_worker_code_v1` 代码提案请求/响应和 Worker v4 作业入口。
2. 新增 RD-Agent Qlib 代码提案生成器，固定模型、提示版本、代码大小和输出结构。
3. Host 研究循环按轮写代码、执行沙箱、读取有限指标并反馈下一轮，默认最多 3 轮。
4. 隔离产物清单记录所有尝试、代码哈希、容器镜像、依赖锁、环境、日志、指标和错误。
5. 封存产物为只读，支持独立审核目录复制和篡改检测。
6. 新增人工提升记录，要求审核人、原因、来源实验和清单哈希，不创建自动发布路径。
7. 完成恶意代码、断网、路径逃逸、OOM、超时、产物篡改、重复启动、崩溃恢复和清理测试。
8. 更新 TODO、文档、version、changes、diffs 和 M5 总验收。

## 验证

- Worker 代码协议、研究循环和人工提升单元测试。
- 真实沙箱短代码读取 Qlib 快照并产出指标。
- 全部 tests、监测站后端测试、JavaScript、编译和 Compose 检查。
- 正式候选库、正式因子目录和主行情库测试前后哈希不变。

## 边界

- 沙箱代码不能直接创建候选、审批或发布。
- 不调用付费模型，使用确定性 Mock Worker 验证闭环。
- 沙箱研究指标不作为正式研究质量或审批证据。
