# 20261101-13 计划：解析文本型 PDF 并分类金融研报

- 日期：2026-11-01
- 版本：V148
- 类型：feat
- 进度任务：P2-02

## 目标

在 P2-01 资料输入与失败契约之上，实现文本型 PDF 的单文件和目录解析，
按确定性规则筛选金融研报，并保证单个文件失败不中断整批处理。

## 实现

- 引入固定版本 `pypdf`，提供页级正文、正文哈希和页级来源引用。
- 新增文件发现、批次解析、失败映射和资源限制；单文件解析失败返回独立记录。
- 使用“研报标题信号 + 至少两个金融领域词”的分类规则，只检查元数据标题和前两页。
- 新增解析与分类契约、错误码和安全业务日志，不持久化正文。
- 更新公开导出、模块文档、根进度、版本、进度、变更和差异记录。

## 验证

- 构造真实文本 PDF、非目标 PDF、损坏 PDF 和加密 PDF。
- 覆盖单文件、目录、失败隔离、内容变化、资源限制、分类哈希和日志脱敏。
- 回归资料契约、依赖、日志、项目布局和挖掘模块测试。
- 执行 Python 编译检查和 `git diff --check`。

## 边界

- 不实现 OCR、因子字段抽取、模型调用、候选生成、审批、发布或正式因子写入。
- 不修改 V1/V2 状态机、Worker 协议或数据库 schema。
- 用户已有的 `TODO_docs/` 文件迁移不纳入本轮提交。
