# V130-3/V130-4 实施计划：Pareto 入围与研究质量状态

## 任务信息

- 日期：2026-10-29
- 版本：V130
- 任务：P4.6 实现 Pareto 前沿和多样性入围；P4.7 区分执行与质量
- 类型：feat

## 目标

使用质量、增量价值、稳定性和覆盖率建立确定性 Pareto 前沿，每个相关簇最多选择一个
候选；同时把评估执行状态和研究质量结论拆开，避免执行成功被误认为质量通过。

## 实施范围

1. 冻结相关性、稳定性和质量选择阈值，并兼容旧上下文默认值。
2. 从选择期评分卡构造 Pareto 目标和证据完整性状态。
3. 按非支配层级、相关簇、内容哈希和候选 ID 选择最多指定数量的最终候选。
4. 新增 `execution_failed / quality_failed / quality_passed /
   evidence_insufficient` 研究质量结论。
5. 将选择结果写入冻结事件，缺证据候选不按零值参与 Pareto。
6. 覆盖权衡排序、输入顺序、簇去重、证据缺失和四类质量状态。

## 验证

- Pareto、质量、控制器、上下文、搜索编排、评分卡和 API 定向测试。
- `compileall` 和 `git diff --check`。

## 边界

- Pareto 只读取选择期证据。
- 质量通过不等于审批通过。
- 不修改 V1 生产链路。
