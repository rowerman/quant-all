# V128-4 实施计划：持久化幂等搜索轨迹

## 任务信息

- 日期：2026-10-29
- 版本：V128
- 任务：P1.3 实现运行内轨迹和幂等写入
- 类型：feat

## 目标

把 V2 假设、实验批次、候选谱系、逐轮证据和控制器决策串成可查询轨迹。同一 turn
重复提交必须返回原记录，不同内容明确冲突，父节点不能跨运行，轨迹内容被修改时
能够通过链式哈希发现。

## 实施范围

1. 增加 `trace_entry` 链式哈希表和 turn 状态机。
2. 实现 `begin_turn()`、候选写入、证据写入、决策写入和 turn 状态迁移。
3. 实现轨迹查询、单对象查询和轨迹完整性校验。
4. 覆盖幂等、冲突、跨运行父节点、重开存储和篡改检测。
5. 更新 V2 搜索文档和进度记录。

## 验证

- V2 轨迹定向测试。
- V2 存储、迁移、契约和 V1 存储回归测试。
- `git diff --check`。

## 边界

- 不实现 LLM 调用、控制器评分或搜索编排。
- 不改变 V1 状态机、候选存储和生产运行链。
