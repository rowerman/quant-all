# 20261102-4 P3-04 自由探索 Web/API 入口

## 目标

完成 `FACTOR_MINING_PROGRESS.md` 的 P3-04：让监测站明确区分手工假设、自由探索和
资料驱动输入，在 V2 API 与页面开放自由探索模式和可选种子，并展示冻结预算、当前消耗、
停止原因与安全提示。

## 范围

- `POST /api/mining/runs` 接受 `hypothesis` 与 `free_exploration` 输入模式。
- 自由探索可提供 `0～2^64-1` 的可选种子，不提供初始假设。
- 运行列表和详情返回安全的模式、种子、种子来源及首轮方向摘要。
- 页面增加自由探索模式，并展示预算、停止原因和防泄漏提示。
- 不修改数据库 schema，不迁移旧运行，不调用真实付费 Worker。
- 不在这里实施 P3-05 的完整端到端、取消恢复和防泄漏联合验收。

## 接口设计

1. `input_mode` 缺省为 `hypothesis`；自由探索必须令 `hypothesis` 为空。
2. `exploration_seed` 只允许自由探索使用，缺失时继续由请求哈希派生有效种子。
3. `search_v2` options 返回可选输入模式、种子范围和固定安全提示。
4. V2 运行摘要返回 `input_mode`、配置种子、有效种子和种子来源。
5. V2 运行详情返回首轮冻结方向的安全摘要；方向尚未生成时返回空值。
6. 公开视图不包含 Prompt、密钥、主机绝对路径、原始 Worker 请求或隐藏思维链。

## 实施步骤

1. 扩展 V2 搜索 Web 服务的请求字段和公开视图。
2. 扩展运行列表存储摘要，避免逐运行额外查询。
3. 修改新建页和运行页，增加自由探索模式、预算与停止原因展示。
4. 增加 API、契约、脱敏和视图测试。
5. 更新浏览器夹具与页面验收脚本。
6. 更新挖掘文档、项目指南、根进度、版本和记录。

## 验收

- 旧手工假设请求保持兼容，自由探索无需初始假设即可提交。
- 非法模式、种子或自由探索携带假设时返回明确稳定错误。
- 页面可切换三种输入来源，自由探索模式不要求假设。
- 运行页展示有效种子、首轮方向、冻结预算、消耗和停止原因。
- 390px 页面可用，页面无 JavaScript 错误，公开响应无敏感字段。
