# 20261101-14 计划：抽取研报因子字段和可审计来源

- 日期：2026-11-01
- 版本：V149
- 类型：feat
- 进度任务：P2-03

## 目标

在已完成的文本型 PDF 解析和金融研报分类之上，使用现有 DeepSeek Worker 从页正文中
抽取因子名称、经济机制、公式、变量、预期方向和可证伪条件，并把每个字段绑定到
资料 ID、正文哈希、页码和可逐字验证的原文片段。

## 实现

- 新增资料抽取契约和公共入口，区分 `explicit`、`inferred`、`missing` 字段证据。
- 按正文大小切分带重叠的页窗口；只接受当前金融研报解析结果，引用错误时整份资料失败。
- 新 Worker v5 协议、固定提示版本、独立子进程、HTTP 作业路由和主服务客户端。
- 原文字段必须与指定页面逐字匹配；模型推断不能标记为原文事实。
- 增加稳定错误码、安全日志、公开导出、模块文档、版本和进度记录。

## 验证

- 覆盖契约、引用篡改、隐藏字段、窗口切分、去重、空结果、资源和安全限制。
- 使用 Flask 假 Worker 覆盖鉴权、幂等、取消、超时、错误协议和客户端轮询。
- 回归资料解析、Worker、日志、错误和项目布局定向测试。
- 执行 Python 编译检查和 `git diff --check`。

## 边界

- 不实现 P2-04 的相关性、可行性、重复度筛选、`HypothesisCard` 或 DSL 草稿。
- 不修改数据库 schema、V1/V2 状态机、Web 页面、审批、发布或正式因子目录。
- 不调用真实付费 Worker，不提交用户已有的 `TODO_docs/` 文件迁移。
