# V164：展示 V3 持久化运行详情

## 目标

按 `FACTOR_MINING_PROGRESS.md` 的优先级实施 P5-02，使 V3 运行详情使用真实持久化
轨迹，不再返回硬编码的空假设、空轮次、零分支、空资料和空自由探索信息。

## 需求明细

- V164-1：抽取 V2/V3 共享运行详情投影。
- V164-2：返回真实假设、turn、候选谱系和分析工具调用。
- V164-3：返回自由探索种子、有效种子、种子来源和首轮方向。
- V164-4：返回脱敏资料运行状态与摘要。
- V164-5：增加 V3 API 详情回归并保持 V2 兼容。

## 实施状态

已完成。

## 实现结果

- 新增 `backend.mining_search_detail`，统一组装运行轨迹、尝试、评分卡、统计诊断、
  资料摘要、自由探索方向和分析工具调用。
- V2 服务继续返回原有字段；V3 服务复用同一投影，并补充 V3 输入/来源身份。
- V3 运行视图从持久化 `SearchRunRequest` 恢复种子信息。
- V3 API 新测试覆盖真实 turn、工具调用、候选计数和自由探索首轮方向。
