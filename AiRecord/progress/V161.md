# V161：P4-05 V3 四类来源端到端闭环

## 目标

把手工假设、自由探索、资料驱动和 CoSTEER 人工提升统一到 V3 可恢复运行、五阶段审核、
人工审批和共享原子发布链路，并补齐页面、监控与最终验收。

## 需求明细

- V161-1：新增 `mining_v3.runtime_*` 运行表并复用既有搜索机制。
- V161-2：新增 `researchrun_` 请求身份和 V3 搜索编排。
- V161-3：运行候选自动同步 V3 来源、候选包络和五阶段证据。
- V161-4：增加服务端人工提升记录读取、校验和 CoSTEER 种子导入。
- V161-5：增加 `MINING_SEARCH_V3_ENABLED`、四类新建入口、V3 运行与候选页面。
- V161-6：增加 V3 状态监控接口和 `MINING-164/165` 稳定错误码。
- V161-7：完成相关单元、联合、浏览器、移动端和静态检查。

  `mining_v3.runtime_*` 表。

  测试段控制，运行 ID 为 `researchrun_`。
- V161-3 已完成：运行候选登记、证据写入和状态迁移同步到统一 V3 契约。
