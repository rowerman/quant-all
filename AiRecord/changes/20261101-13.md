# 2026-11-01 V148：解析文本型 PDF 并分类金融研报

## 实际修改

- 新增 `mining.research_material_parser`，提供单文件、显式路径列表和文件/目录目标的
  PDF 解析入口，并逐文件隔离预期和未预期解析失败。
- 新增页正文、分类、解析限制、单文件结果和批次结果契约；批次结果明确区分
  `financial_research`、`filtered` 和 `failures`。
- 新增确定性金融研报分类器，使用 NFKC 归一化、研报标题信号、金融领域词双门槛和
  稳定信号哈希；分类只读取元数据标题和前两页。
- 扩展资料文件发现与安全路径解析，支持递归目录、稳定排序、跳过目录内符号链接和
  显式非 PDF 失败。
- 固定 `pypdf==6.21.2`，同步直接依赖、完整锁文件和依赖测试；新增
  `MINING-152` 资料资源上限错误。
- 解析记录保存页数、完整正文哈希和页级来源引用；原始页正文仅保留在内存解析结果，
  资料业务日志继续使用白名单和脱敏字段。
- 更新资料模块文档、错误码、依赖说明、根进度、版本、进度和差异记录。

## 验证结果

- 新增真实 PDF 测试覆盖目标和非目标分类、多页正文、目录扫描、非 PDF 过滤、损坏 PDF、
  加密 PDF、无正文 PDF、缺失文件、符号链接替换、文件在指纹后变化、文件/页数/单页
  字符限制、未知解析异常继续处理、页级来源引用、严格契约和日志脱敏。
- 资料、依赖、日志和项目布局定向测试：`57 passed in 1.95s`。
- 完整挖掘回归：`474 passed、10 failed in 512.20s`；失败均为既有
  `tests/test_mining_analysis_tools.py` schema 歧义。
- `pip check` 通过。

## 未覆盖限制

- 不实现 OCR、字段抽取、LLM 调用、候选生成或运行入口。
- 不提供 PDF 子进程超时隔离；只执行文件大小、页数和正文字符限制。
- 不修改候选、审批、发布、正式因子、V1/V2 状态机、Worker 协议或数据库 schema。
