# 2026-11-02 V153：自由探索初始方向

## 结果

完成 P3-02。没有用户初始假设时，主服务可从冻结字段和算子目录确定生成一个可审计的
首轮研究方向，再交给现有 V2 Worker 生成候选。方向、随机种子和生成依据在首次 Worker
调用前冻结，恢复时不会重新抽样。

## 实际修改

- `SearchRunRequest` 增加仅用于自由探索的 `exploration_seed`，范围为 `0～2^64-1`。
  未提供种子时从请求哈希派生，旧请求和 P3-01 自由探索请求保持兼容。
- 新增 `ResearchDirection` 契约，保存机制类别、字段依赖、表达复杂度、最大深度、种子
  来源、请求、上下文和 profile 哈希，并派生稳定方向哈希和方向 ID。
- 新增八类固定机制配置：价格趋势、短期反转、波动、流动性、估值、盈利能力、成长和
  现金流质量；生成器只使用冻结目录，无法生成时返回 `MINING-161`。
- V2 首次搜索在调用 Worker 前写入 `free_exploration_direction_planned` 事件，并把
  方向写入初始假设 metadata。首轮 Worker 使用方向声明的最大表达式深度。
- 手工假设继续使用原初始假设和深度；未修改 V1、Worker 协议、数据库 schema、Web 或
  API 模式入口。
- 更新挖掘契约、V2、Web、项目指南、模块入口、错误表、根进度、版本和本轮记录。
