# 2026-11-02 V154：自由探索方向池与停止控制

## 结果

完成 P3-03。自由探索分支不再直接采用 Worker 返回的下一假设，而是由主服务从冻结方向
池选择结构化语义未使用的方向；Worker 只在该方向内生成候选。重复方向进入尝试台账，
不会创建新的假设、批次或候选。修订轮保留当前方向和最大表达式深度。

## 实际修改

- `ResearchDirection` 增加 `semantic_material()` 和 `semantic_hash`，只按机制类别、
  排序后的数据依赖、预期方向和表达复杂度判重。
- 新增 `mining.free_exploration_pool`，按种子稳定排列机制并轮转字段与复杂度组合；
  分支计划保存方向池哈希、选中方向、跳过的重复方向和稳定计划哈希。
- V2 逐轮编排在自由探索 `branch` 时使用主服务方向，`refine` 继承原方向；Worker 的
  分支建议不再直接物化。
- 重复方向写入 `duplicate` 尝试并绑定当前 turn 和假设。计划按目标 turn 之前的历史
  重建，目标假设已存在时校验并复用，避免重复计数或事件哈希漂移。
- 现有轮次、分支、候选和连续无改善停止预算保持不变；没有数据库表变更、迁移、
  正式数据修改或 Worker 协议变更。
- 更新挖掘契约、V2、Web、项目指南、模块入口、根进度、版本和本轮记录。
