# 2026-10-29 V128-3：建立 V2 存储和显式 V1 迁移

## 实际修改

- 新增共享候选库文件锁，V1 和 V2 存储使用同一把 `.state.lock`；V1 行为保持不变。
- 新增独立 `mining_v2` schema，覆盖上下文、运行、turn、假设、实验批次、候选谱系、
  证据、决策、尝试记录、作废记录、计数、事件和 V1 迁移快照。
- 新增 `SearchRunRequest` 和 `MiningV2Store`，支持新库初始化、幂等创建运行、运行
  查询和事件读取。
- 新增 `migrate_v1_to_v2()` 与 `python -m mining.migrate_v1_to_v2` 命令。
- 迁移在同一事务内创建 schema 并复制 V1 上下文、运行和候选快照，最后写入源快照
  哈希；中断整体回滚，重复迁移幂等，源 V1 变化和活动运行明确拒绝。
- V1 快照通过 V2 存储只读查询，并固定返回 `read_only=true`、`resumable=false`。
- 更新 V2 存储和迁移文档。
