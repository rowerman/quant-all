# 2026-10-29 V131：M4 受控分析工具基础

## 实际修改

- 新增 `mining_analysis_tool_v1` 目录，固定字段、算子、运行摘要、候选证据、
  相关性、消融和窗口邻域共 7 个工具。
- 工具请求严格限制工具名、参数、调用 ID、4 次预算和 64 KiB 结果；未知工具、
  未知参数和超限结果明确拒绝。
- 新增主服务 `AnalysisToolGateway`，只读取当前运行的冻结开发期证据，不接受 SQL、
  路径、表名、日期切片、数据库连接或代码参数。
- 新增 `mining_worker_v3` discover/finalize 工具补充协议；保留 Worker v1/v2 服务，
  Worker 在收到一次工具结果后必须返回最终决策。
- `mining_v2` 增量增加工具缓存和审计表；缓存只在本运行复用，缓存命中仍写审计并
  计入调用次数。
- 搜索编排支持工具补充、取消和从已完成 discover/finalize 作业恢复，不重复调用
  已提交作业。
- V2 Web 选项暴露工具启用状态和固定目录，默认启用，可通过
  `MINING_ANALYSIS_TOOLS_ENABLED=0` 显式关闭。
