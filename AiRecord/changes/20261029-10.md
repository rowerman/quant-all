# 2026-10-29 V129-4：实现逐轮 V2 搜索闭环

## 实际修改

- 新增 V2 运行状态机，状态固定为 `queued → searching → selecting → evaluating →
  holding_out → review_ready`，并支持中断、失败、取消和 stale 收口。
- 新增 V2 运行控制表，持久化真实状态、取消请求、停止原因、当前动作、无改善计数和
  上一轮最佳质量向量。
- 新增不可变评估证据表，保存技术、开发、选择、完整和测试段的脱敏指标与错误摘要，
  不保存行情值或评估文件路径。
- 新增 `MiningSearchOrchestrator`，按轮执行 Worker v2 请求、DSL 二次校验、批量物化、
  开发期评估、证据包、确定性决策和下一假设。
- 单个候选门禁或快速评估失败只登记失败，不阻断同轮其他候选；非法草稿进入尝试台账。
- 选择期使用独立评估器和确定性排序，结果不反馈给 Worker；最终研究期只评估入围候选，
  模块测试段每运行最多领取一次。
- 调整 V2 Worker 请求允许首轮无证据，从第二轮起强制提供开发期证据。
