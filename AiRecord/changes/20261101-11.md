# 2026-11-01 V146：完成沙箱安全验收

## 实际修改

- `DockerSandboxRunner` 改为先解析 Docker 镜像 ID，再使用不可变 ID 启动容器；新增
  core dump、单文件大小和文件描述符限制，并在宿主侧持续监控标准输出、错误输出和
  工作区容量。超时、输出或工作区超限均终止并清理容器。
- `SandboxExecutionResult` 增加可选 `limit_exceeded`，尝试台账增加资源限制原因、
  工作区安全违规和实际执行代码哈希。
- 研究循环在容器退出后复核 `proposal.py`。自改、删除或替换代码按 `MINING-144`
  失败，恢复原始提案并保留实际执行哈希；符号链接和特殊文件删除后记录相对路径。
- 新增 `verify_qlib_snapshot()`，研究启动前校验完整快照文件集合、普通文件类型、
  大小和 SHA-256。`verify_artifact_tree()` 同步拒绝清单外文件、缺失文件和符号链接。
- 新增沙箱安全验收测试，覆盖故障注入、恢复、不可变镜像、输出/工作区越限、自改代码、
  知识污染、快照/产物污染，以及真实 `quant-mining-sandbox:s5` 镜像的断网、只读根、
  只读快照和非 root 边界。
- 更新沙箱威胁边界、安全验收矩阵、测试映射、根进度、版本和 V146 进度记录。
