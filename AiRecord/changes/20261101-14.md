# 2026-11-01 V149：抽取研报因子字段和可审计来源

## 实际修改

- 新增 `mining_research_extraction_v1` 契约，固定六类因子字段及
  `explicit/inferred/missing` 证据状态；每个非缺失字段至少绑定一条页码引用。
- 新增研报窗口抽取入口，按 24000 字符和 512 字符重叠切分，最多调用 8 个窗口。
  重叠窗口产生的完全相同草稿按内容哈希去重。
- 新增 Worker v5 请求、响应、子进程生成器和 `/v5/jobs` 路由，提示版本为
  `mining_research_extraction_prompt_v1`。
- Worker 只返回页码与逐字短句；主服务在完整页正文中重新定位，生成页内偏移、摘录
  哈希、字段声明哈希、草稿 ID 和结果 ID。
- 新增 HTTP 抽取客户端，支持提交、轮询、鉴权和错误映射。
- 新增 `MINING-153`～`MINING-155`，分别表示抽取契约、引用/安全校验和资源上限错误。
- 发送 Worker 前如果检测到疑似密钥或主机绝对路径则拒绝；业务日志只记录标识、模型、
  窗口数、因子数、缺失字段数、状态和耗时。
- 更新公开导出、资料、Worker 和工程文档、根进度与版本记录。
