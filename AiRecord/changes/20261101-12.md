# 2026-11-01 V147：定义资料驱动输入与可追溯契约

## 实际修改

- 新增 `mining.research_materials` 及其输入契约、解析记录、安全规则和文件指纹模块，
  为 P2-02 的 PDF 读取固定资料 ID、哈希、解析器版本、来源和失败边界。
- 资料 ID 基于内容 SHA-256 稳定生成；清单哈希覆盖路径、媒体类型、大小、内容和解析器
  版本，并对输入顺序和创建时间保持稳定。
- 解析成功与失败记录严格互斥；失败分类固定映射 `MINING-148`～`MINING-151`。
- 文件指纹使用相对 POSIX 路径和 1 MiB 流式读取，拒绝路径穿越、盘符、符号链接、
  根目录外目标、非普通文件和批内重复内容。
- 失败消息、来源定位和日志字段增加密钥与主机路径脱敏；资料日志只允许 ID、哈希、
  状态和统计字段。
- 更新挖掘模块导读、资料契约文档、项目错误码、根进度、版本和 V147 进度记录。
