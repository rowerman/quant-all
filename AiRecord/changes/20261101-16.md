# 2026-11-01 V151：资料驱动运行入口与 V2 闭环

## 结果

新增 `POST /api/mining/research-runs` 和资料模式页面。用户可在固定
`data/source/reports` 根目录下指定相对 PDF 文件或目录；后台完成文本 PDF 解析、
Worker v5 字段抽取、Worker v6 DSL 转换和预算内自动准入，再进入现有 V2 开发期、
选择期、完整评估、一次性测试段、人工审批和原子发布链路。

## 实际修改

- 新增资料运行输入、摘要、逐草稿结论和候选来源契约；候选来源保存相对资料路径、内容与
  解析哈希、六字段、页码、偏移、短引用、变量映射和版本信息，不保存完整正文。
- 新增 `mining_v2.research_run` 和 `mining_v2.research_candidate`。候选来源哈希写入
  `CandidateDefinition.parameters`，因而进入候选内容哈希；详情、审批和发布加载均校验，
  来源篡改会阻断审批和发布。
- 转换通过项按 `(document_id, draft_id)` 自动准入到每运行候选预算；超出预算项记录
  `admission_budget_exhausted`。资料种子批次最多登记 24 个候选，但普通搜索 Worker
  仍保持每轮最多 4 个。
- 资料首轮不调用搜索生成 Worker，直接进入开发期评估；后续修正和分支继续使用原 V2
  Worker。选择期、最终研究期和测试段不会进入研报抽取、转换或 Agent 请求。
- 页面新增手工/资料模式；运行页展示资料、抽取、转换和准入摘要，候选页展示页码短引用。
  新增浏览器验收脚本和确定性资料样例，截图写入
  `AiRecord/evidence/mining_research_web/`。
- 新增 `MINING-159` 资料运行契约错误和 `MINING-160` 无可准入候选错误；更新资料、
  V2、Web、API、项目指南、版本和根进度文档。

## 未覆盖与限制

- 未调用真实付费 Worker。
- 不支持浏览器上传、扫描件 OCR、Word/HTML 和远程 URL。
- 不实现 P3 自由探索或 P4 V3 统一来源模型。
- 正式发布 `source_kind` 保持 `v2_search`，以兼容既有下游读取。
