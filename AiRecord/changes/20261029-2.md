# 2026-10-29 V128-2：冻结分层搜索窗口

## 实际修改

- 新增 `SearchWindows`，冻结开发期、选择期、最终研究期和模块测试段，强制顺序递增
  且不重叠。
- 新增 `SearchConfig` 和 `configs/mining/search.json`，保存窗口、默认搜索预算和
  `mining_search_v2` 版本；运行加载时拒绝非冻结窗口。
- 新增 `FrozenSearchContext`，对窗口、预算、目录、正式因子清单和数据指纹生成稳定
  上下文哈希。
- 新增 Agent、控制器、最终评估器和测试段执行器四种访问角色。
- 新增 `worker_view()`、`ensure_agent_visible()` 和工作载荷安全检查，递归拒绝选择期、
  最终研究期和测试段字段，并限制 Agent 日期范围只能位于开发期。
- `ExperimentBatch` 和 `EvidencePacket` 在构造时再次校验开发期，防止调用方绕过。
- 新增 `MINING-125` 可见性错误，更新 V2 搜索文档。
