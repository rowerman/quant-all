# 2026-10-29 V128-5：增加搜索预算和尝试台账

## 实际修改

- 新增 `record_trial()`、单条/全部尝试查询、分类计数和审核摘要。
- 尝试按 `trial_key` 幂等；提出、拒绝、重复、非法、门禁失败、快速评估、完整评估和
  测试段领取使用独立计数。
- 新增 `invalidate_trial()`，通过追加无效标记保留原尝试，不减少原分类计数。
- 新增 `transition_candidate()`，候选状态、尝试记录、分类计数和事件在同一事务提交。
- turn、分支、每分支修正、每 turn/每运行候选、完整评估和测试段领取均按冻结预算
  校验；配置变化不能扩大既有运行。
- 尝试记录和作废记录纳入链式轨迹，可检测内容篡改。
