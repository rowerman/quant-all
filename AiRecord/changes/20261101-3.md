# 2026-11-01 V138：实现 V2 候选审批状态与证据哈希

## 实际修改

- 新增 `mining.search_review`，定义 `SearchApprovalEvidence`、
  `SearchApprovalEligibility` 和审批记录防篡改哈希。审批证据覆盖候选内容、语义哈希、
  冻结上下文以及全部候选级评估证据引用。
- 新增 `mining_v2.search_approval` 表及索引；已有 V2 数据库打开时会通过现有 DDL
  自动补表，不提升 `mining_v2` schema 版本。
- 新增 V2 审批只读和写入存储混入：提供审批资格、当前证据哈希、审批读取、有效性检查、
  最终批准或拒绝，以及原子候选状态迁移。
- 审批要求 `technical`、`development`、`selection`、`full`、`holdout` 证据均存在且
  全部通过；缺失、失败、候选或上下文变化、相反决定和重复备注冲突均被拒绝。
- 审批记录、候选 CAS 状态、审批事件和 `search_approval` 链式轨迹在同一事务中写入；
  审批表正文被篡改时，完整轨迹校验会失败。
- 更新挖掘桥接、V2 搜索、项目导读、监测站 API 和根进度文档。P0-02 标记完成，
  下一项为 P0-03。
