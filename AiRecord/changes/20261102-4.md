# 2026-11-02 V155：自由探索 Web/API 入口

## 结果

完成 P3-04。监测站现在可以在 V2 模式下从手工假设、自由探索和资料驱动三种来源创建
运行。自由探索不需要初始假设，可提交 `0～2^64-1` 的可选种子；留空时继续由请求哈希
派生有效种子。

## 实际修改

- `POST /api/mining/runs` 接受 `input_mode` 和 `exploration_seed`。自由探索禁止携带
  假设；非法模式、负数种子或越界种子返回 `MINING-101`。
- 页面使用十进制字符串提交种子，服务端在构造 `SearchRunRequest` 前转换为整数，
  避免浏览器超过 `2^53-1` 后丢失精度。API 仍接受 JSON 整数。
- V2 运行列表返回 `source_mode`，区分手工假设、自由探索和资料驱动；运行详情返回
  配置种子、有效种子、种子来源和首轮冻结方向。
- 新建页增加自由探索入口、可选种子和防泄漏说明。运行页增加研究输入、首轮方向、
  全部冻结预算、当前消耗和明确停止原因。
- 资料驱动仍使用独立接口；原有手工假设请求和已有 V2 运行保持可读。
- 没有数据库表变更、迁移、正式数据修改或 Worker 协议变更。
