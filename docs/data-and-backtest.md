# 数据与回测口径

## 价格

- 因子和标签使用后复权价。
- 回测成交使用原始价。
- 公司行动通过账本处理，避免把复权价格隐式当成真实成交价。

## 时间点

- 交易日收盘生成信号，下一交易日开盘执行。
- 指数池使用上一个已结束月份的月末成分快照。
- 财务字段在公告日之后才可用。
- 全 A 股票池保留历史退市股票，降低幸存者偏差。

## 交易规则

- 停牌、ST、涨跌停、退市整理期和上市天数参与可交易判断。
- 主板、创业板、科创板和北交所使用各自申报单位。
- 账本记录 T+1、佣金、印花税、过户费、滑点、冲击成本和现金缓冲。
- 卖不掉或资金不足的仓位会保留并影响后续组合，不按零成交收益处理。

## 回测输出

结果包含逐日净值、成交、拒单、持仓、目标权重、资金分配、公司行动、行业暴露和绩效
指标。分块回测先完成因果分段，再统一拼接报告。

回测通过只说明给定数据和规则下的执行结果，不证明未来收益。
