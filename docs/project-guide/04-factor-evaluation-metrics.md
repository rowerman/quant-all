# 因子评估指标

本页逐项说明因子详情页和对比页当前展示的 13 个指标。计算实现在
[research/evaluation/calculate/metrics](../../research/evaluation/calculate/metrics)，
前端渲染实现在 [apps/monitor/frontend/charts.js](../../apps/monitor/frontend/charts.js)。

## 1. 统一口径

### 1.1 符号

| 符号 | 含义 |
|---|---|
| `F(i,t)` | 股票 `i` 在交易日 `t` 的因子值 |
| `Y(i,t;H,P)` | 未来 `H` 日、价格通道 `P` 的收益标签 |
| `U(i,t)` | 股票是否属于评估股票池 |
| `M(i,t)` | 当日总市值 |
| `Q` | 分位组数 |
| `S_t` | 因子与标签同时有限的当日有效股票集合 |

### 1.2 标签

页面可选择 1/3/5/10/15/20 日：

```text
close 通道：t 日收盘 -> t+H 日收盘
open 通道：t+1 日开盘 -> t+1+H 日开盘
```

价格使用后复权。`t` 日停牌、未来价格不足或标签不可得时为空。不同周期独立取有效样本，
长周期在评估区间末端天然少几天，不做填充。

### 1.3 股票池

全 A 池要求当日可买、非 ST、非退市整理期并上市满 60 个自然日。指数池使用上一个已结束
月份的月末权重快照，再应用相同可交易过滤。

### 1.4 共用统计量

对于有效逐日序列 `x_1...x_n`：

```text
mean      = 平均值(x)
std       = 样本标准差(x)，ddof=1
stderr    = std / sqrt(n)
IR        = mean / std
t         = mean / stderr = IR * sqrt(n)
win_rate  = count(x > 0) / n
Sharpe    = mean / std * sqrt(252)
NAV_t     = NAV_(t-1) * (1 + x_t)
drawdown_t = NAV_t / max(NAV_0...NAV_t) - 1
```

普通 t 值和 Sharpe 没有处理重叠持有期或自相关。研究结论应结合有效天数与市场状态。

## 2. 指标一：覆盖率与取值分布

注册 key：`coverage`

### 2.1 回答的问题

因子在评估区间是否有足够数据，是否只对部分股票或部分日期有定义，数值分布是否退化。

### 2.2 计算

```text
全样本覆盖率 = 因子非空行数 / 面板总行数
池内覆盖率   = 池内因子非空行数 / 池内总行数
有效配对率   = 池内因子与标签同时非空行数 / 池内总行数
```

另外输出：

- 行列数、股票数、交易日数。
- 缺失数和非有限值数。
- 每日有效配对数的均值、中位数、最小值、最大值。
- 池内因子均值、标准差、最小/最大值、偏度和超额峰度。
- 1%、5%、25%、50%、75%、95%、99% 分位点。

### 2.3 意义

- 池内覆盖低说明因子只覆盖部分股票，不能把 IC 当作全市场结论。
- 覆盖高但有效配对率低，通常说明标签缺失、停牌或区间末端不足。
- 标准差接近 0 表示截面区分度弱。
- 偏度和峰度大说明长尾明显，Pearson IC 更容易受极端值影响。
- 每日有效配对数波动大时，各日 IC 的可比性会下降。

列表页的“平均覆盖率”来自因子目录库；详情页覆盖率来自当前区间和股票池，两者不能混用。

## 3. 指标二：IC / RankIC 汇总

注册 key：`ic_stats`

### 3.1 计算

对每个交易日有效集合 `S_t`：

```text
IC_t = corr(F(i,t), Y(i,t))
RankIC_t = corr(rank(F(i,t)), rank(Y(i,t)))
```

Pearson 默认对因子和标签按日做 3 倍 MAD 去极值；关闭后使用原始值。RankIC 使用原始值
的平均并列名次，不做 MAD 去极值。

再对日序列输出均值、样本标准差、ICIR、t 值、正值比例和有效天数：

```text
ICIR = mean(IC_t) / sample_std(IC_t)
```

页面同时比较 RankIC 方向与因子定义方向。因子方向为 `1` 时均值理想上为正，为 `-1`
时理想上为负。

### 3.2 意义

- 绝对值越大，截面预测关系越强。
- RankIC 更关心排序，对极端值通常更稳健。
- ICIR 衡量单位波动下有多少平均预测力。
- 有效日少于 20 天时只显示样本不足，不输出统计结论。
- 多日标签重叠会破坏日度独立性，t 值只能作参考。

## 4. 指标三：IC 时序

注册 key：`ic_series`

### 4.1 计算

保留每个交易日的 IC、RankIC 和有效股票数 `n_t`，并计算：

```text
rolling_IC_t = average(IC_(t-19)...IC_t)
rolling_RankIC_t = average(RankIC_(t-19)...RankIC_t)
cumulative_IC_t = sum(有效 IC_0...IC_t)
```

滚动窗口使用 `min_periods=1`。前端当前展示累计 IC 与累计 RankIC。

### 4.2 意义

- 长期围绕 0 说明预测方向弱或不稳定。
- 持续在 0 一侧说明方向较稳定。
- 多次穿越 0 可能表示市场状态依赖或因子衰减。
- 单日尖峰必须结合 `n_t`，少数股票形成的相关更容易异常。

## 5. 指标四：IC 分布

注册 key：`ic_dist`

### 5.1 计算

对有效的日度 IC 和 RankIC 分别建立 40 个等宽桶，同时输出均值、标准差、偏度、
超额峰度和 5/25/50/75/95 分位点。横轴范围由实际最小/最大值决定，不固定为 `[-1,1]`。

### 5.2 意义

- 分布重心偏正或偏负，表示总体方向。
- 分布越宽，日间预测能力波动越大。
- 均值和中位数差异大，说明少数日期造成偏斜。
- 两端长尾应回查对应日期、市场事件和有效股票数。

## 6. 指标五：分位平均收益与单调性

注册 key：`bin_returns`

### 6.1 分组

每天只用池内因子非空股票：

```text
average_rank = 因子值在当日截面中的平均名次
position = ceil(average_rank / 当日有效股票数 * Q)
bin = clip(position, 1, Q)
```

组 1 是最低因子组，组 Q 是最高因子组。标签缺失的股票保留分组，但不进入该组收益均值。

### 6.2 收益

等权：

```text
R_equal(t,q) = average(Y(i,t) | bin(i,t)=q)
```

组内市值加权：

```text
R_mv(t,q) = sum(M(i,t) * Y(i,t)) / sum(M(i,t))
```

仅使用市值非空且大于 0 的股票。每个组输出日收益序列的均值、标准差、标准误、t 值、
正值比例和有效天数。

单调性不是回归斜率，而是分位编号与各组平均收益之间的 Spearman 相关：

```text
monotonicity = corr(rank(1...Q), rank(mean_R_1...mean_R_Q))
```

### 6.3 意义

- 高分位高、低分位低且单调性接近 1，支持“因子越大越看多”。
- 单调性接近 -1 可能是反向因子，或因子方向元数据有误。
- 只有最高组异常而中间无梯度，更接近尾部信号。
- 等权与市值加权差异大，说明收益可能集中于特定规模股票。

## 7. 指标六：分位累计净值

注册 key：`bin_curves`

### 7.1 计算

净值固定使用 1 日前瞻收益，不使用页面选择的多日主标签：

```text
NAV(t,q) = NAV(t-1,q) * (1 + R_1d(t,q))
```

等权和组内市值加权分别生成一组曲线。缺失日收益按 0 处理，因此当日净值不变。

### 7.2 意义

- 曲线用于比较分位组合的相对路径。
- 高分组长期高于低分组，说明排序具有持续收益区分力。
- 曲线交叉说明效果可能随市场状态变化。
- 该曲线没有 T+1、涨跌停、停牌成交、佣金、税费、滑点和资金约束，不是回测净值。

固定使用 1 日收益的原因是多日标签相互重叠。把 5 日或 20 日收益逐日累乘会重复计入
同一持有区间，无法解释组合净值。

## 8. 指标七：多空价差

注册 key：`spread`

### 8.1 计算

```text
Spread_t = R_1d(t,Q) - R_1d(t,1)
```

分别计算等权和市值加权：

- 日度价差序列。
- 多空净值 `cumprod(1 + Spread_t)`。
- 均值、标准差、t 值、正值比例和有效天数。
- 年化 Sharpe。
- 累计收益和最大回撤。

### 8.2 意义

- 均值正表示最高因子组平均跑赢最低组。
- 正值比例高表示多数日期同向。
- 最大回撤反映价差曲线经历过的最深损失。
- 当前研究口径忽略融券、做空限制、T+1 和交易成本，不能视为可执行多空策略收益。

## 9. 指标八：分位收益分布

注册 key：`bin_dist`

### 9.1 计算

提供两种分布：

1. **每日分位均值分布**：先计算每天每组平均收益，再把日度组均值跨日期汇总为箱线数据。
2. **分位内个股收益分布**：汇总池内全部个股期收益，按分位生成分布。

两者都给出最小值、分位数、中位数、最大值、均值、标准差和样本数。

### 9.2 意义

- 中位数和均值差异大，说明收益分布偏斜。
- 箱体很宽表示组内日期间或个股间差异大。
- 各组箱体重叠严重时，即使均值有梯度，截面区分也未必稳定。
- 收益分布整体移动比只有均值移动更有说服力。

## 10. 指标九：分位换手与因子自相关

注册 key：`turnover`

### 10.1 分位换手

先把分位编号转成交易日 × 股票宽表，只比较昨天和今天都属于股票池且都有分组的连续样本。

全池换手：

```text
Turnover_t = 今天换到不同分位的连续样本数 / 今天和昨天都有分组的样本数
```

单组换手：

```text
Turnover(t,q) =
昨天在 q、今天仍在池内但不在 q 的股票数
/
昨天在 q 且今天仍在池内的股票数
```

新进入或退出股票池的样本不进入这个指标。

### 10.2 因子自相关

每天先做截面秩，再比较当前和滞后集合的同一批股票：

```text
Autocorr(t,L) = corr(rank(F(i,t)), rank(F(i,t-L)))
```

页面展示滞后 1、5、20 个交易日。

### 10.3 意义

- 换手低，组合成员更稳定，潜在交易成本压力较小。
- 自相关高，信号持续时间长，可降低调仓频率。
- IC 高但自相关低，信号可能短促，需要关注交易成本。
- 这里的分位换手不是实际成交换手，也没有权重变化、费用和成交限制。

## 11. 指标十：多周期衰减

注册 key：`decay`

### 11.1 计算

在 1/3/5/10/20 日五个标签上分别计算：

- RankIC 均值。
- RankICIR。
- t 值。
- 正值比例。
- 有效天数和有效配对数。

每个周期只使用自己的有效配对，不用其他周期填补。页面还输出：

```text
多头超额 = 最高分位收益 - 池内因子非空样本平均收益
多空价差 = 最高分位收益 - 最低分位收益
```

两项分别提供等权和组内市值加权。

### 11.2 意义

- 短周期强、长周期弱，信号可能有效期较短。
- 长周期仍稳定，可能适合较低换手策略。
- 多头超额强、多空价差弱，说明信号可能主要来自高分位。
- 多空价差强、多头超额弱，说明低分位表现较差也可能是主要来源。
- 各周期持有区间重叠，不能把它们当独立实验比较 t 值。

## 12. 指标十一：风格暴露

注册 key：`exposure`

### 12.1 七个风格

| 风格 | 当前近似定义 |
|---|---|
| SIZE | `ln(total_mv)` |
| VALUE | `z(1/pb)` 与 `z(1/pe_ttm)` 的均值 |
| MOMENTUM | `close[t-20] / close[t-250] - 1` |
| SHORT_REV | `1 - close[t] / close[t-20]` |
| VOL | 60 个有效交易日日收益标准差 |
| LIQUIDITY | 20 个有效交易日平均换手率 |
| BETA_60 | 个股收益对沪深 300 收益的 60 日回归斜率 |

### 12.2 回归

回归样本是池内且因子非空股票，不要求标签非空：

```text
z(F(i,t)) =
alpha_t
+ beta_SIZE,t * z(SIZE(i,t))
+ ...
+ beta_BETA60,t * z(BETA60(i,t))
+ error(i,t)
```

因子和风格在同一样本上按日做 3 倍 MAD 去极值和 z-score。风格缺失时在标准化后填 0，
这是回归中的中性假设，不代表真实暴露为零。

每日截面 OLS 后汇总：

- 日度系数均值。
- 系数时序标准差。
- Fama-MacBeth t 值。
- 系数为正的日期比例。
- 日度 t 绝对值大于 1.96 的比例。
- 有效回归日、跳过日和平均 R²。

单日样本少于 30、响应变量恒定、设计矩阵秩亏时跳过当日。有效回归日少于 20 天只报
样本不足。

### 12.3 意义

- 绝对暴露大且显著，说明因子可能是该风格的代理。
- 平均 R² 高表示七个风格能解释较多因子截面变化。
- 正暴露比例高表示方向稳定。
- 行业层默认关闭；静态行业分类可能带来历史前视和退市股缺失。

## 13. 指标十二：剔除风格后的增量 IC

注册 key：`incremental_ic`

### 13.1 计算

先取得风格回归残差 `E(i,t)`，再在与标签同时有效的同样本上计算：

```text
ResidualRankIC_t = corr(rank(E(i,t)), rank(Y(i,t)))
RawRankIC_t = corr(rank(F(i,t)), rank(Y(i,t)))
```

原始 RankIC 必须使用残差计算成功的完全相同日期和股票，不能直接搬到 overview 的原始
RankIC。页面输出：

- 原始与残差 RankIC 的均值、IR、t、正值比例和有效天数。
- 两条逐日序列。
- `delta = raw_mean - residual_mean`。
- `survivor_share = residual_mean / raw_mean`。

### 13.2 意义

- 残差 IC 接近原始 IC，说明信号相对独立于七个风格。
- 残差 IC 明显下降，说明部分预测力可被风格解释。
- `delta` 是同一样本下的差值，不是各风格可加贡献。
- `survivor_share` 只是均值比例，不是解释率，可能小于 0 或大于 1。

## 14. 指标十三：与已有因子的相关性

注册 key：`correlation`

### 14.1 计算

对评估区间和股票池中的每个因子对 `(a,b)`：

1. 按交易日取两个因子的有限交集。
2. 在交集内重新计算平均并列名次。
3. 计算日度 Spearman。
4. 对有效日期做等权平均。

```text
Correlation(a,b) = average_t(rho(a,b,t))
```

单日少于 5 只股票不计数，少于 20 个有效交易日不报告均值。Top-N 按绝对值降序并保留
符号，同时排除当前因子自身；全矩阵按因子目录自动扩展。

### 14.2 意义

- 接近 1 表示排序高度重复。
- 接近 -1 表示方向相反，可能是同一信号的镜像。
- 接近 0 只表示截面排序弱相关，不代表收益预测力无关。
- 高相关因子是否删除还要结合 IC、换手、成本和可解释性。
- 每对因子使用不同交集，时间均值矩阵不保证半正定，不能直接用于组合优化。

## 15. 推荐阅读顺序

1. 覆盖率：确认样本是否足够。
2. IC/RankIC：确认方向和平均预测力。
3. IC 时序与分布：确认是否靠少数日期驱动。
4. 分位收益与单调性：确认是否存在完整横截面梯度。
5. 净值、多空和收益分布：观察路径与尾部。
6. 换手、自相关和衰减：判断信号周期与成本压力。
7. 风格暴露、增量 IC 和相关性：判断冗余与独立信息。

## 16. 系统边界

- 页面只展示计算结果，不在浏览器重算指标。
- 完整分析受 2400 个交易日和约 800 万面板行保护。
- 全历史只开放轻量 IC，不代表其他指标也能全历史运行。
- 所有分位、净值和多空结果都是研究分析，不包含完整交易规则和执行成本。
- 所有结论依赖日期、股票池、标签周期、价格通道和因子方向，跨参数比较前必须确认口径。
