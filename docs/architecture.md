# 系统架构

```text
Tushare / gbbq
      |
      v
数据获取 -> 清洗复权 -> DuckDB -> 因子 Parquet
                               |       |
                               v       v
                           因子评估   模型训练
                               \       /
                                v     v
                               组合回测
                                   |
                                   v
                          FastAPI / SSE / Web
                                   ^
                                   |
               受控 LLM Worker -> 人工审批 -> 原子发布
```

## 数据层

`core/data` 负责取数、清洗、复权和建库。`quant` 是统一读取入口，暴露日线、标签、
财务、指数、行业、公司行动和因子面板。

## 研究层

`core/factors` 定义因子；`calculate` 构造统一评估面板并计算指标；
`alpha` 负责周频数据集、模型训练、预测、监控和最终留出。

## 挖掘层

`mining` 管理冻结上下文、受控 DSL、候选评估、状态机、人工审批和正式发布。
LLM 输出始终视为不可信输入，由主服务重新解析、校验和命名。

## 交易层

`backtest` 把信号转换为执行日目标权重，由 `LedgerPortfolio` 记录现金、持股、交易规则、
成本、税费和公司行动。

## 应用层

`backend` 提供 REST、SSE、调度、取消和静态页面。因子评估、挖掘和回测共享进程级容量
与原生计算锁。
