# 因子质量监测口径

计算包入口和全部函数用法以 `research/evaluation/calculate/README.md` 为准；后端只做接口调度，
前端只展示，数据库与因子parquet均只读，评估结果不落库。

批量数组接口位于 [`kernels`](../../core/kernels/README.md)。相关性、IC/RankIC、多周期
衰减和增量 IC 默认使用 `auto`：扩展可用时分别走 C++ Spearman、逐日排名和 Pearson，
缺失时回退 Python；分箱、MAD/z-score、OLS 等其余计算仍使用原 Python/NumPy 实现。
`calculate.native` 仍只负责并发锁。

P1-03 的正式三年相关性 stage 由 Python `217.770s` 降至 native `140.460s`。P1-04 的
固定三年面板中，`overview` 由 `4.661s` 降至 `2.239s`，`decay` 由 `15.145s` 降至
`5.371s`，`incremental_ic` 由 `21.727s` 降至 `16.298s`；Python/native/auto payload
在 `1e-10` 内一致。

正式因子和自动挖掘候选通过 `FactorView` 指向各自的 Parquet 来源；`evaluate_context()`
在已构建面板上复用同一套指标。正式入口 `evaluate()` 保持原行为，候选路径不能绕过
`build_panel()` 的股票池、标签和面板资源校验。

新增相关性：同区间、同股票池，逐日对每个因子对的有限交集重新计算平均并列排名
Spearman；不筛收益标签、不做MAD。单日至少5只股票，至少20有效日才报告均值。
Top-N按相关性的绝对值降序，保留符号，排除自身；全矩阵展示全部已注册且落盘因子，
并提供各对有效日数。成对样本不同，因此时间均值矩阵不保证半正定，不能直接当作
组合优化的协方差矩阵。因子目录扩展时自动跟随，不硬编码29。

IC/RankIC在每个周期独立有限配对内计算；ICIR=时间均值/样本标准差，
t=均值/标准误，重叠持有期收益与时序相关会影响t的解释。
分位图以固定平均名次规则分箱，两种权重为等权和分位内总市值加权。
缺少有效正市值的样本不进入加权；净值固定使用1日标签，避免重叠期累乘。
图表是研究分析，不代表可以执行的净交易收益。

风格为7个Barra近似项，静态行业默认关闭。风格缺失的中性填补不能理解为事实上
没有暴露；残差RankIC与原始RankIC按同样本对照，差值不是可加贡献，比例不是解释率。
指数池使用上一个已结束月份的月末快照；上市满60日指自然日。

全历史轻量IC可用；完整分析保留2400个交易日及按年份parquet元数据估算的800万行
保护。估算是保守上界，部分年份的短区间也可能被拒绝，按提示缩小年份范围即可。
对比最多4因子顺序计算，各因子的有效覆盖与标签配对可能不同。
