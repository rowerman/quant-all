# 前端因子计算指标说明

> 依据代码版本：2026-10-14
>
> 适用页面：`#/factor/<因子名>` 的单因子分析、`#/compare` 的因子对比
>
> 计算实现：`research/evaluation/calculate/metrics/`、`research/evaluation/calculate/daily.py`、`research/evaluation/calculate/binning.py`
>
> 页面实现：`apps/monitor/frontend/app.js`、`apps/monitor/frontend/charts.js`

## 1. 说明范围

前端通过后端 SSE 按阶段接收指标结果。当前实际注册并展示 13 个指标，顺序如下：

1. 覆盖率与取值分布
2. IC / RankIC 汇总
3. IC 时序
4. IC 分布
5. 分位平均收益与单调性
6. 分位累计净值
7. 多空价差
8. 分位收益分布
9. 分位换手与因子自相关
10. 多周期衰减
11. 风格暴露
12. 剔除风格后的增量 IC
13. 与已有因子的相关性

本文说明的是当前代码的实际计算口径，不把页面上的研究展示结果等同于可直接执行的交易回测结果。

## 2. 统一数据口径

### 2.1 评估面板

一次评估先构造一张共享面板。后续指标都从这张面板计算，因此同一次请求中的指标使用相同的因子值、标签、股票池和日期范围。

对股票 `i`、交易日 `t`，记：

- `F(i,t)`：因子值；
- `U(i,t)`：股票是否属于当前股票池；
- `Y(i,t; H, P)`：未来 `H` 个交易日、价格通道为 `P` 的前瞻收益标签；
- `M(i,t)`：总市值，用于市值加权；
- `Q`：分位组数，前端可选 5、10、20 组。

前瞻收益标签来自 `md.fwd_return`，价格使用后复权价格：

- `close` 通道：从 `t` 日收盘价到 `t+H` 日收盘价；
- `open` 通道：从 `t+1` 日开盘价到 `t+1+H` 日开盘价。

标签周期可选 1、3、5、10、15、20 个交易日。评估主标签由页面的“标签周期”和“价格通道”决定，例如 `horizon=5`、`price=close` 时，主标签是 `fwd_ret_close_5`。

默认的全 A 股票池不是全市场所有股票，而是同时满足以下条件的股票：

- 当日可以按收盘口径买入；
- 不是 ST；
- 上市满 60 个自然日。

指数股票池使用上一个已结束月份的月末指数权重快照，再叠加同一套可交易性过滤，避免把当月后来才披露的信息用于当月评估。

### 2.2 有效样本与共同门槛

- IC、RankIC 和多周期 RankIC 只使用“因子值与对应标签同时非空且有限”的股票；
- 单个交易日有效配对少于 5 只时，该日不参与相关系数统计；
- 多数时序质量指标在有效交易日少于 20 天时只显示有效天数，不显示数值结论；
- 各周期标签独立取有效样本，长周期在区间末端天然会少一些样本，不做填充；
- 分层只由因子值决定，不因为标签缺失而改变分组；标签缺失的股票只是不进入该组的收益统计；
- 页面选择“Pearson 去极值”时，只对 Pearson IC 的因子和标签按交易日做 3 倍 MAD 去极值，RankIC 不做去极值；
- 分层收益提供两种口径：组内等权、组内按 `total_mv` 加权。市值缺失或不大于 0 的股票不进入市值加权口径。

### 2.3 共用统计量

对一条有效日序列 `x_1, ..., x_n`，代码中的通用统计量为：

- 均值：`mean = average(x)`；
- 样本标准差：`std = std(x, ddof=1)`；
- 标准误：`stderr = std / sqrt(n)`；
- 信息比率：`IR = mean / std`；对 IC 序列就是 ICIR；
- t 值：`t = mean / stderr = IR * sqrt(n)`；
- 正值比例：`win_rate = count(x > 0) / n`；
- 年化夏普：`mean / std * sqrt(252)`，不扣交易费用、不减无风险利率；
- 累计净值：从 1 开始逐日计算 `NAV_t = NAV_{t-1} * (1 + x_t)`；
- 最大回撤：当前净值相对历史最高净值的最小跌幅，结果为负数，例如 `-0.12` 表示最大回撤 12%。

## 3. 指标一：覆盖率与取值分布

### 3.1 是什么

覆盖率回答的是：这个因子在评估面板里是否有值，以及这些值有多少能和未来收益标签配对。它是判断因子数据质量的第一步，不能直接代表预测能力。

### 3.2 怎么计算

页面显示以下三类覆盖率：

1. **全样本覆盖率**

   `coverage_all = 因子非空行数 / 面板总行数`

   它包含股票池外行，因此反映因子落盘对整个评估面板的覆盖情况。

2. **池内覆盖率**

   `coverage_universe = 股票池内因子非空行数 / 股票池内总行数`

   这是因子在真正参与分析的股票池中的覆盖率。

3. **有效配对率**

   `pair_coverage = 池内同时有因子和标签的行数 / 股票池内总行数`

   这是最接近 IC 实际可用样本比例的指标。标签在停牌日、区间末端或未来价格不足时可能为空，因此它通常低于池内覆盖率。

另外还统计：

- 面板总行数、池内行数、股票数、交易日数；
- 因子缺失值数、正负无穷值数；
- 每日有效配对数的均值、中位数、最小值和最大值；
- 池内因子值的均值、标准差、最小值、最大值、偏度、超额峰度，以及 1%、5%、25%、50%、75%、95%、99% 分位点。

### 3.3 有什么含义

- 覆盖率低：因子可能只对部分股票或部分日期有定义，IC 和分层结果的样本代表性会变差；
- 覆盖率高但有效配对率低：问题主要在标签或可用交易日，而不一定在因子本身；
- 均值、标准差和分位点可用于发现因子是否几乎为常数、极端值过多或数值范围异常；
- 偏度和峰度高通常说明因子分布长尾，Pearson IC 可能更容易受极端值影响；
- 每日有效配对数波动很大时，逐日 IC 的可靠性也会随日期变化。

列表页的“平均覆盖率”来自因子目录库的落盘统计，详情页本次评估的覆盖率来自当前日期区间和股票池，二者不是同一个统计量。

## 4. 指标二：IC / RankIC 汇总

### 4.1 是什么

IC 衡量因子值和未来收益在每个交易日的截面线性相关程度；RankIC 衡量二者的截面排序是否一致。二者都先逐日计算，再对日期做时间序列汇总。

### 4.2 怎么计算

对每个交易日 `t`，在有效配对集合 `S_t` 上计算：

**Pearson IC**：

`IC_t = corr(F(i,t), Y(i,t))`

默认先对当日的因子和标签分别做 3 倍 MAD 去极值，再算 Pearson 相关；关闭“Pearson 去极值”后直接使用原始值。

**RankIC**：

`RankIC_t = corr(rank(F(i,t)), rank(Y(i,t)))`

这是逐日截面 Spearman 相关。因子值或标签并列时使用平均名次。RankIC 直接对原始值排名，不使用 Pearson 的 MAD 去极值。

对日度序列分别计算均值、样本标准差、标准误、ICIR、t 值、正值比例和有效日数：

- `ICIR = mean(IC_t) / std(IC_t)`；
- `RankICIR = mean(RankIC_t) / std(RankIC_t)`；
- `t = 均值 / 标准误`；
- 正值比例是每日相关系数大于 0 的比例。

同时把 RankIC 均值与因子定义中的方向比较：

- 因子定义为“越大越看多”时，RankIC 均值应为正；
- 因子定义为“越大越看空”时，RankIC 均值应为负。

### 4.3 有什么含义

- IC 或 RankIC 的绝对值越大，表示因子排序与未来收益的截面关系越强；
- RankIC 比 Pearson IC 更关注排序，通常对极端数值更稳健；
- ICIR 反映平均预测能力相对于日间波动的稳定程度；
- t 值可用于判断均值是否明显偏离 0，但重叠持有期会产生时序相关，不能机械地把 t 值当作严格独立样本检验；
- 正值比例高表示多数交易日方向一致，但它没有体现每个交易日相关系数的大小；
- “方向一致”只说明实测方向与因子定义一致，不等于预测能力显著。

有效交易日少于 20 天时，页面保留有效天数，但将均值、标准差、ICIR、t 值和正值比例置空，避免用极短样本得出结论。

## 5. 指标三：IC 时序

### 5.1 是什么

IC 时序展示每个交易日的 IC、RankIC、有效配对数以及 RankIC 的滚动均值，用来观察预测能力是否稳定、是否集中在某些阶段。

### 5.2 怎么计算

- 每个交易日的 IC 和 RankIC 使用上一节的逐日公式；
- `n_t` 是该日同时拥有因子值和标签的有效股票数；
- 20 日滚动 IC 均值：`rolling_IC_t = average(IC_{t-19}, ..., IC_t)`；
- 20 日滚动 RankIC 均值同理；
- 滚动窗口使用 `min_periods=1`，所以序列开始部分不足 20 天时也会显示已有样本的均值。

前端使用两条折线显示累计 IC 和累计 RankIC。累计序列按日期逐日求和；无效日保留为空，但不把空值当成数值累加，也不会污染后续有效日的累计结果。

### 5.3 有什么含义

- 日度 IC/RankIC 长期围绕 0：因子信号弱或不稳定；
- 滚动均值长期在 0 上方或下方：说明方向具有一定持续性；
- 滚动均值频繁穿越 0：可能存在市场状态依赖或因子衰减；
- 单日极端峰值要结合有效样本数 `n_t` 查看，样本很少时更容易被少数股票决定。

## 6. 指标四：IC 分布

### 6.1 是什么

IC 分布把日度 IC 和 RankIC 分成 40 个等宽区间，以直方图观察相关系数集中位置、离散程度和尾部。

### 6.2 怎么计算

对有效的日度 IC 序列和 RankIC 序列分别调用 40 桶直方图统计，另外计算：

- 样本数；
- 均值；
- 样本标准差；
- 偏度；
- 超额峰度；
- 5%、25%、50%、75%、95% 分位点。

直方图的横轴区间由该序列的最小值和最大值决定，不是固定的 `[-1, 1]` 网格。

### 6.3 有什么含义

- 分布整体偏向正侧或负侧，反映因子方向的总体倾向；
- 分布宽，说明因子日间预测能力波动大；
- 中位数和均值差异大，说明分布可能偏斜；
- 两端长尾表示少数日期贡献了较大的相关系数，应回看这些日期的市场状态和样本数；
- IC 分布不能替代时序检验，也不能单独说明因子收益是否可交易。

## 7. 指标五：分位平均收益与单调性

### 7.1 是什么

它把每个交易日的股票按因子值分成 `Q` 组，比较从低因子组到高因子组的未来收益是否呈现稳定、单调的梯度。

这是分层检验，不是逐笔交易回测。

### 7.2 怎么分组

仅使用“属于股票池且因子非空”的股票。对每个交易日：

1. 按因子值从小到大排序；
2. 并列值使用平均名次；
3. 计算 `position = ceil(average_rank / 样本数 * Q)`；
4. 将组号限制在 `1` 到 `Q`；
5. 组 1 是最低因子组，组 `Q` 是最高因子组。

标签为空的股票仍然保留分组，但在收益统计时剔除。

### 7.3 怎么计算收益

对每个交易日和分位组 `q`：

- **等权收益**：

  `R_{t,q}^{equal} = average(Y(i,t) | bin(i,t)=q)`

- **分位内市值加权收益**：

  `R_{t,q}^{mv} = sum(M(i,t) * Y(i,t)) / sum(M(i,t))`

然后对每个分位的日度组收益序列计算均值、标准差、标准误、t 值、正值比例和有效天数。

**单调性**不是回归斜率，而是“分位组编号”和“各组平均收益”之间的 Spearman 相关：

`monotonicity = corr(rank(1, ..., Q), rank(mean(R_1), ..., mean(R_Q)))`

只使用有有效均值的组。接近 1 表示收益随因子分位整体上升，接近 -1 表示整体下降，接近 0 表示没有清晰单调关系。

### 7.4 有什么含义

- 高分位收益高、低分位收益低且单调性接近 1：支持“因子越大越看多”；
- 高分位收益低且单调性接近 -1：可能是反向因子，或因子方向元数据需要检查；
- 只有最高组有效、其他组没有梯度：因子可能只区分尾部，不能称为完整单调；
- 等权和市值加权差异大：因子效果可能主要来自小盘或大盘股票；
- 分层均值和 t 值基于重叠的持有期标签时，t 值不应被当作独立日收益检验。

## 8. 指标六：分位累计净值

### 8.1 是什么

它把各分位组合的日度收益累乘成从 1 开始的净值曲线，观察不同因子组的长期相对表现。

### 8.2 怎么计算

虽然分位平均收益使用页面选择的主标签周期，但净值曲线固定使用 `label_1d`，也就是 1 日前瞻收益：

`NAV_{t,q} = NAV_{t-1,q} * (1 + R_{t,q}^{1d})`

等权和市值加权分别计算一套曲线。缺失的日度收益在通用累乘函数中按 0 处理，因此该日净值保持不变。

固定用 1 日收益的原因是：如果把 5 日或 20 日重叠收益逐日累乘，同一持有区间会被重复计算，曲线不再代表清晰的持有组合口径。

### 8.3 有什么含义

- 曲线用于比较分位之间的相对路径和最终净值；
- 高分位持续高于低分位，说明因子排序在时间上具有较稳定的收益区分能力；
- 曲线交叉或长期反转，说明因子效果可能具有状态依赖；
- 该曲线没有模拟 T+1、涨跌停无法成交、停牌处理、手续费、印花税、滑点、订单执行和资金约束，因此不是交易回测净值。

## 9. 指标七：多空价差

### 9.1 是什么

多空价差比较最高因子分位和最低因子分位的收益差，集中检验因子排序两端是否拉开。

### 9.2 怎么计算

设最高分位为 `Q`，最低分位为 `1`：

`Spread_t = R_{t,Q}^{1d} - R_{t,1}^{1d}`

代码同样固定使用 1 日前瞻收益，并分别计算等权和市值加权：

- 日度价差序列；
- 多空净值 `cumprod(1 + Spread_t)`；
- 价差均值、标准差、t 值、正值比例和有效天数；
- 年化夏普 `mean(Spread) / std(Spread) * sqrt(252)`；
- 累计收益 `多空净值最后值 - 1`；
- 最大回撤。

### 9.3 有什么含义

- 平均价差为正：高因子组平均跑赢低因子组；
- 正值比例高：价差多数交易日为正；
- 年化夏普高：单位日波动下的价差较好，但没有成本和自相关修正；
- 最大回撤反映价差净值经历过的最深回撤；
- 该指标是研究上的“最高分位减最低分位”，代码明确忽略融券约束、T+1 成交限制和交易费用，不能直接作为可执行多空策略收益。

## 10. 指标八：分位收益分布

### 10.1 是什么

它不是只看每个分位的平均收益，而是展示每个分位收益的整体分布，帮助判断平均值是否被少数极端股票或日期拉动。

### 10.2 怎么计算

有两种展示口径：

1. **每日分位均值分布**

   先对每个交易日、每个分位计算组内平均期收益，再把这些日度组均值跨日期汇总，计算箱线图的最小值、5%、25%、50%、75%、95%、最大值、均值、标准差和样本数。等权、市值加权分别展示。

2. **分位内个股收益分布**

   汇总池内全部个股的期收益，不受权重影响，再按分位计算相同的五数概括与均值、标准差、样本数。

### 10.3 有什么含义

- 中位数与均值差距大：收益分布可能偏斜，平均收益受尾部影响；
- 箱体很宽：组内个股或日期之间差异大，因子并非对所有股票都有效；
- 各组箱体重叠严重：即使均值有梯度，横截面区分度也可能有限；
- 高分位的收益分布整体上移而不是只有均值上移，才更支持因子具有广泛的排序作用。

## 11. 指标九：分位换手与因子自相关

### 11.1 是什么

该指标从两个角度衡量信号稳定性：

- 分位换手：股票的分位组是否经常变化；
- 因子自相关：同一股票的因子截面排序经过若干交易日后是否仍相似。

### 11.2 分位换手怎么计算

先把分位组号转换成“交易日 × 股票”的宽表。只比较今天和上一交易日都在股票池且都有分组的连续样本，不包含新进入或退出股票。

全池分位换手：

`Turnover_t = 今天换到不同分位的连续样本数 / 今天和昨天都有分组的样本数`

单个分位 `q` 的换手：

`Turnover_{t,q} = 昨天在 q、今天仍在池内但今天不在 q 的样本数 / 昨天在 q 且今天仍在池内的样本数`

前端画全池逐日分位换手，并表格展示各分位平均换手和有效天数。

### 11.3 因子自相关怎么计算

先把因子值转换成每日截面秩，再对相同股票集合计算当前日和滞后日的 Spearman 相关。代码展示 `lag1`、`lag5`、`lag20`：

`Autocorr_{t,L} = corr(rank(F(i,t)), rank(F(i,t-L)))`

缺失值按当日配对剔除，单日配对少于 5 只时不产生有效相关系数。

### 11.4 有什么含义

- 换手低：分位组合成员相对稳定，潜在交易成本压力通常较小；
- 换手高：股票频繁跨组，组合调仓更频繁；
- 自相关高：因子排序保持时间较长，信号可能适合较低调仓频率；
- 自相关低但 IC 高：信号可能短促，需要关注短周期收益和交易成本；
- 页面中的分位换手不等同于真实交易换手，不包含新进/退出股票，也没有模拟权重变化、成交限制和费用。

## 12. 指标十：多周期衰减

### 12.1 是什么

它在 1、3、5、10、20 日五个标签周期上重复评估同一个因子，观察预测能力和分层收益随持有周期如何变化。

### 12.2 RankIC 衰减曲线怎么计算

对每个周期 `H` 独立构造有效配对，在该周期上逐日计算 RankIC：

`RankIC_t^{(H)} = corr(rank(F(i,t)), rank(Y(i,t; H)))`

每个周期分别计算 RankIC 均值、RankICIR、t 值、正值比例、有效天数和有效配对数。前端折线显示 RankIC 均值和 RankICIR 随周期的变化。

周期末端不足 `H` 个交易日的标签直接为空，只从对应周期剔除，不用其他周期填补。因此长周期的有效日数和样本数天然可能更少。

### 12.3 多头超额和多空价差怎么计算

各周期还计算两种收益差，均提供等权和分位内市值加权：

- 多头超额：`最高分位收益 - 池内因子非空样本的平均收益`；
- 多空价差：`最高分位收益 - 最低分位收益`。

这些收益差使用对应周期的前瞻收益标签，而不是固定 1 日标签。

### 12.4 有什么含义

- RankIC 在短周期高、长周期逐步下降：信号有效期偏短；
- RankIC 在长周期仍稳定：因子可能适合较长持有周期；
- ICIR 比均值更稳定：均值略有变化但波动明显下降时，长期周期可能更可用；
- 多头超额为正而多空价差不明显：因子可能只提供相对池均值的多头收益，不一定适合做空最低组；
- 多空价差强但多头超额弱：可能主要来自低分位表现差，而非高分位本身强。

各周期的前瞻收益区间重叠，跨周期 t 值不能直接按独立样本解释。

## 13. 指标十一：风格暴露

### 13.1 是什么

风格暴露检查一个因子是否只是某些常见风格的代理。例如一个所谓“新因子”如果几乎完全等同于短期反转或规模风格，那么它的 IC 可能主要来自已有风格，而不是独立信息。

### 13.2 七个风格变量

当前默认使用 7 个 Barra 近似风格：

| 代码 | 含义 | 当前定义 |
|---|---|---|
| `SIZE` | 规模 | `ln(总市值)` |
| `VALUE` | 估值 | `z(1/pb)` 与 `z(1/pe_ttm)` 的均值，缺一个时使用另一个 |
| `MOMENTUM` | 长期动量 | `close[t-20] / close[t-250] - 1` |
| `SHORT_REV` | 短期反转 | `1 - close[t] / close[t-20]` |
| `VOL` | 波动 | 60 个有效交易日的日收益标准差 |
| `LIQUIDITY` | 流动性 | 20 个有效交易日的平均换手率 |
| `BETA_60` | 贝塔 | 对沪深 300 日收益做 60 日一元回归的斜率 |

风格原料和因子在每天的回归样本内都先做 3 倍 MAD 去极值，再做截面 z-score。风格缺失值填为 0，表示回归中的中性填补假设，不表示该股票在现实中没有该风格暴露。

### 13.3 怎么计算

每天做一次截面 OLS，也就是 Fama-MacBeth 的日度截面步骤：

`z(F(i,t)) = alpha_t + beta_SIZE,t * z(SIZE(i,t)) + ... + beta_BETA_60,t * z(BETA_60(i,t)) + error(i,t)`

回归样本是池内且因子非空的行，不要求标签非空，这使风格暴露与页面选择的标签周期解耦。

每个风格最终展示：

- 日度暴露系数的均值；
- 日度系数序列的样本标准差；
- Fama-MacBeth t 值，即系数均值除以系数序列标准误；
- 系数为正的日期比例；
- 日度回归 t 值绝对值大于 1.96 的比例；
- 有效回归日数。

页面还展示逐日系数曲线、逐日 R²、平均 R²、平均回归行数和被跳过的日期数。

单日回归样本少于 30、响应变量无变化、风格无法估计或设计矩阵秩亏时，该日会被跳过。有效回归日少于 20 天时只报样本不足。

### 13.4 有什么含义

- 暴露系数为正：因子值较高的股票通常更偏向该风格；
- 暴露系数为负：因子值较高的股票通常更偏离或反向暴露于该风格；
- 绝对系数大且 t 值明显：因子可能主要是该风格的代理；
- 平均 R² 高：七个风格能解释因子截面变化的比例较高，但不等于解释未来收益；
- 系数正值比例高：暴露方向跨日期更稳定；
- 静态行业层默认关闭。开启 `stock_basic` 后使用静态行业分类，历史行业变化、退市股缺失和行业口径差异会带来解释风险。

暴露系数的 t 值使用普通标准误，没有 HAC 修正，因此在风格系数有明显自相关时只能作参考。

## 14. 指标十二：剔除风格后的增量 IC

### 14.1 是什么

它把因子中能够被七个风格解释的部分剔除，再评估剩余部分对未来收益的 RankIC，用来判断因子是否具有独立于这些风格的预测信息。

### 14.2 怎么计算

先使用上一节的逐日截面回归，得到每个股票的残差 `E(i,t)`。然后在残差与标签都有效的同一批样本上计算：

`ResidualRankIC_t = corr(rank(E(i,t)), rank(Y(i,t)))`

同时，在完全相同的日期和有效配对上，用原始因子重算对照值：

`RawRankIC_t = corr(rank(F(i,t)), rank(Y(i,t)))`

页面展示：

- 原始 RankIC 的均值、IR、t 值、正值比例和有效天数；
- 残差 RankIC 的同一组统计量；
- `delta = 原始 RankIC 均值 - 残差 RankIC 均值`；
- `survivor_share = 残差 RankIC 均值 / 原始 RankIC 均值`；
- 两条逐日 RankIC 曲线。

### 14.3 有什么含义

- 残差 RankIC 接近原始 RankIC：因子能力较少被这七个风格解释；
- 残差 RankIC 明显下降：原始效果中有一部分来自风格暴露；
- 残差 RankIC 仍显著为正或为负：说明剔除风格后仍可能存在独立信号；
- `delta` 只是同样本下的处理前后差值，不是可以逐项相加的风格贡献；
- `survivor_share` 只是两个均值的比值，不是统计意义上的风格解释率，原始均值接近 0 时尤其不稳定，也可能超出 0 到 1 的范围。

一个重要边界是：此处的“原始 RankIC”使用的是残差计算成功且残差 RankIC 有定义的同一批日期，不一定等于“IC / RankIC 汇总”卡片中的全量原始 RankIC。

## 15. 指标十三：与已有因子的相关性

### 15.1 是什么

它衡量当前因子与所有“已注册且已经落盘”的其他因子的截面排序相似程度，用于发现重复因子和评估因子库的风格/信号冗余。

### 15.2 怎么计算

对当前评估区间和股票池：

1. 按月份读取已落盘因子；
2. 对每个交易日、每一对因子取两列的有限值交集；
3. 在该交集内重新计算平均并列名次；
4. 计算该日的 Spearman 相关；
5. 对每一对因子的有效日期做时间等权平均。

记因子 `a`、`b` 的逐日相关为 `rho_{a,b,t}`，则：

`Correlation(a,b) = average_t(rho_{a,b,t})`

单日有效股票少于 5 只不计入，少于 20 个有效交易日的因子对返回空值。相关性矩阵会给出所有因子对及其有效日数；Top-N 列表按相关性绝对值从高到低排序，保留相关性的正负号，并排除当前因子自身。

该计算不筛收益标签、不做 MAD 去极值，且不同因子对可能使用不同的股票交集和日期集合。

### 15.3 有什么含义

- 相关性接近 1：两个因子的排序非常相似，可能重复表达同一信号；
- 相关性接近 -1：排序方向相反，可能是同一信号的正反版本；
- 相关性接近 0：截面排序关系弱，但不代表收益预测能力互不相关；
- 高相关因子不一定都不能保留，仍需结合 IC、覆盖率、换手和交易成本判断；
- 这个矩阵是不同成对样本上的时间均值，不保证半正定，不能直接当作组合优化的协方差矩阵。

## 16. 如何组合阅读

建议按以下顺序解读一只因子：

1. **先看覆盖率**：确认因子是否有足够的池内数据和有效标签配对；
2. **再看 IC / RankIC**：确认方向、平均预测力和稳定性；
3. **再看 IC 时序和分布**：确认结论是否由少数日期驱动；
4. **再看分位收益和单调性**：确认是否存在从低分位到高分位的完整梯度；
5. **再看净值、多空和收益分布**：观察长期路径、尾部风险和等权/市值加权差异；
6. **再看换手、自相关和衰减**：判断信号有效期和潜在调仓压力；
7. **最后看风格暴露、增量 IC 和因子相关性**：判断因子是否只是已有风格或已有因子的重复表达。

## 17. 当前系统边界

- 前端图表和表格只消费后端计算结果，不在浏览器重新计算指标；
- 完整分析有 2400 个交易日和约 800 万面板行的保护上限，全历史只支持轻量 IC；
- 当前页面没有完整模拟 T+1、涨跌停无法成交、停牌期间不可交易、佣金、印花税、滑点、订单执行和资金占用；
- 分位净值和多空曲线是研究展示口径，不是可直接用于实盘或策略收益承诺的回测结果；
- 风格暴露使用七个近似风格，行业层默认关闭，开启静态行业分类时存在历史时点不一致风险；
- 所有指标结论都依赖所选日期区间、股票池、标签周期、价格通道和因子方向定义，跨参数直接比较前应确认口径一致。
