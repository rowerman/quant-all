# 回测模块完整性评估

> 评估日期：2026-10-19。范围是日频、只做多、A 股股票现货研究回测。
> 结论基于当前代码、`data/databases/quant.duckdb` 的实际覆盖、回测测试和已有审计记录。

## 总体结论

**主流程完整，可以闭环完成 A 股日频股票回测；边界事件并不完整。**

从策略版本、取数、股票池、信号、执行、公司行动、成本、绩效、分块、落库到接口和页面，
当前模块已经形成一条可复现的完整链路。对普通的因子 Top-N、指数增强、择时和日频目标权重
策略，只要不跨越未建模的公司行动事件，结果可以作为研究依据。

但“流程完整”不等于“所有 A 股事件都被精确还原”。当前仍有几类会改变净值的缺口，
其中最重要的是并购重组/换股吸收合并和北交所转板。它们只在持仓撞上事件时触发，
但触发时会把持仓按零价值核销，属于静默偏差。

- `data/databases/quant.duckdb`：日线 17,999,882 行、5,913 只股票，覆盖 2000-01-04~2026-10-15；
  公司行动 64,618 条、6,286 只股票。

  覆盖 2004-12-31~2026-10-15。

  状态提供者 11 轮收敛）的审计全部通过：费用逐笔偏差 0、现金裁剪 0、
  目标股数差额 0、区间末退市残留 0、退市整理期买入 0。

## 关键缺口

### 1. 并购重组与换股吸收合并（P2-2B，已跳过）

触发条件：回测在合并退市日仍持有目标股票。

当前处理：所有正式退市都走同一个零价值核销路径，持仓变成 0 现金。实际经济结果应当是
按换股比例转成收购方股份，或按现金对价结算。

影响：单只持仓记 -100%，会直接改变组合净值、回撤、Alpha、Beta 和策略间比较。
未持有该股票时不触发，基准也不受影响。

已知样本：

| 股票 | 最后有效成交 | 退市日 | 说明 |
|---|---|---|---|
| 海通证券 `SH600837` | 2025-02-05 | 2025-03-04 | 退市前长期停牌，实际换股为 `国泰海通` |
| 中国重工 `SH601989` | 2025-08-12 | 2025-09-05 | 退市前长期停牌，实际换股为 `中国船舶` |
| 东兴证券 `SH601198` | 尚未到 | 2026-10-19 | 与信达证券同日退市 |
| 信达证券 `SH601059` | 尚未到 | 2026-10-19 | 与东兴证券同日退市 |

### 2. 北交所转板

北交所公司转板到科创板或创业板后，旧代码退市、新代码上市。当前没有事件映射，
持仓跨越转板日时同样会被零价值核销。

已知样本：`BJ832317` 观典防务转板到 `SH688287`，`BJ833874` 泰祥股份转板到 `SZ301192`，
`BJ833994` 翰博高新转板到 `SZ301321`。这类事件与并购重组同属“跨证券持仓转换”，
但不在 P2-2B 的名称范围内。

### 3. 退市原因没有区分

当前没有保存“破产退市、主动退市、现金要约、换股合并”等退市原因。零价值核销对破产退市
是保守近似，对现金要约或换股合并则是错误处理。P2-2B 跳过后，这个限制保留。

### 4. 现金余额不计息

无风险利率只用于夏普、Sortino、Alpha 等指标，现金余额本身不产生利息。
对长期满仓策略影响较小；对高现金仓位、择时或防御型策略，组合收益会被系统性低估。

### 5. 成交模型是日频近似

所有成交按执行日开盘价加固定滑点和平方根冲击处理，成交额参与率默认 10%。
没有集合竞价队列、盘口深度、部分成交、盘中撤单和收盘价成交。对流动性较好的股票
通常足够；对涨跌停附近、停牌复牌和小市值股票，成交可能偏乐观或偏保守。

### 6. 研究与归因能力边界

当前没有 Brinson 行业/个股归因、因子暴露归因、滚动绩效、参数寻优、walk-forward、
多策略资金分配和组合优化。它们影响研究深度，不影响单次回测的主流程。

### 7. 次要但应知道的近似

- 指数成分快照断档时只记录 WARNING，并按当月空池处理；长区间使用指数池时应检查日志。
- 红股（送股）目前只调整持股和成本价，没有把红股面值计入红利税应税基础；
  现金分红已按 FIFO 递延计税。
- 停牌除权日出现零头折现时，参考价会退回当日全市场开盘价中位数，属于近似处理。
- 经手费、证管费等交易所规费没有单列，默认由佣金费率覆盖；提高佣金假设时应一并考虑。

## 适用判断

| 使用场景 | 是否可用 | 说明 |
|---|---|---|
| 日频因子 Top-N、指数增强、择时、目标权重提供者 | 可用 | 主流程完整；注意停牌、涨跌停、容量和现金缓冲口径。 |
| 2026-09-01~2026-10-15 的短区间研究 | 可用 | 区间在 2026-10-19 换股合并之前，当前样本不触发 P2-2B。 |
| 跨越 2015~2025 的全 A 长区间 | 有条件可用 | 若持仓撞上换股合并或转板，结果会被污染；需要按事件清单复核。 |
| 高现金仓位、长期择时策略 | 有条件可用 | 现金不计息会低估收益；应把现金利息纳入敏感性分析。 |
| 分钟级、T+0、做空、融资融券、ETF/可转债 | 不可用 | 当前模块明确不支持。 |
| 生产级全事件仿真 | 不完整 | 还需要并购重组、转板、退市对价和更细的成交模型。 |

## 建议的复核方式

在 P2-2B 保持跳过的情况下，长区间回测至少做一次“事件撞仓”检查：

1. 从 `bt.holding` 取事件日仍有持仓的股票；
2. 与人工维护的换股合并/转板清单按 `stock_code + delist_date` 对齐；
3. 若命中，标记该运行受未建模公司行动影响，不直接用净值下结论；
4. 对高现金策略，额外跑一版“现金按无风险利率计息”的敏感性对照。

当前短区间 `2026-09-01~2026-10-15` 不包含 2026-10-19 的东兴/信达合并，
因此这批结果不受 P2-2B 影响。
