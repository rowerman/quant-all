# 已知限制

本项目可以用于研究工程复现和方法验证，但不能据此宣称稳定超额收益或可直接实盘交易。

## 研究结论

- 2024-2026 最终留出已按冻结口径消耗一次，状态为 `fail_final_holdout`。
- LightGBM 主候选年化净收益为 15.37%，净超额 3.33%，最大回撤 -45.54%。
- 简单全因子 rank 基线在留出期的收益、Sharpe 和最大回撤均优于主候选。
- 2024 年净超额为 -31.46%，收益高度集中在 2025 年。
- 最终留出失败后不能在同一窗口继续调参并重新宣称独立验证成功。

## 统计口径

- 周频 5 日标签存在持有期重叠，普通独立样本 t 值和 ICIR 只能作为研究参考。
- 因子评估的 IC 和收益序列默认没有 HAC/Newey-West 标准误。
- 部分因子评估图表不包含交易成本、容量和完整执行约束。
- 开启静态行业层时仍可能受到历史分类前视和退市股缺失影响。
- 自动挖掘测试段与历史模型最终留出存在区间重叠，不属于全项目独立样本。

## 回测边界

- 收盘信号、次日开盘执行仍是日频近似，不模拟盘中成交过程。
- 不模拟集合竞价队列、盘口深度、部分成交、撤单和交易所撮合优先级。
- 不模拟融资融券、做空、ETF、可转债、现金利息和跨品种对冲。
- 不模拟并购重组、换股吸收合并和北交所转板映射。
- 指数成分使用月末快照，但数据源修订、权重延迟和快照断档仍会留下风险。
- 1000 万元和 1 亿元档容量表现明显变差，小资金结果不能外推。

## 系统边界

- 项目没有券商接入、实盘订单、账户对账、实时推送和自动交易。
- FastAPI 服务绑定本机并假设单 worker，没有身份认证和多租户隔离。
- 原生计算锁只覆盖正式服务入口，直接并发调用底层函数不受同等保护。
- 自动挖掘依赖外部模型服务，生成路径不完全确定，且默认不自动批准候选。
- 本地完整数据库、模型和日志不进入 Git，真实数据结果仍依赖本地清单和哈希。

## 数据和依赖

- 合成演示数据不包含真实行情，仅用于代码链路验证。
- Tushare、gbbq、RD-Agent、Qlib、VectorBT 和其他上游资源继续遵守各自许可。
- 真实数据可能被上游修订，结论需要绑定具体提交、配置、数据版本和运行 ID。
