# 自动因子挖掘

自动挖掘把研究假设或资料转换为受控因子表达式，再经过技术门禁、快速筛选、完整评估、
模块测试段和人工审批。

## 安全边界

- LLM 只返回候选草稿，不直接执行 SQL 或 Python。
- 主服务在冻结字段和算子范围内重新解析和校验表达式。
- 候选名称、依赖、回看窗口和哈希由主服务计算。
- Worker 运行在独立 Docker 环境，不读取行情库或正式候选库。
- 候选必须人工批准，之后才能进入正式因子发布。

## 研究窗口

搜索运行区分开发期、选择期、最终研究期和一次性模块测试段。Worker 只能看到开发期，
评估器只访问对应窗口。运行开始后修改配置不会改写已有冻结上下文。

## 版本兼容

V1 是兼容入口，V2 提供证据驱动搜索，V3 是当前推荐入口，M5 提供默认关闭的隔离代码
研究。旧运行可以迁移或只读查看，正式候选都需要审批和原子发布。

## 研究边界

模块测试段与历史模型最终留出存在区间重叠，因此不能把它表述为全项目独立样本发现。
自动挖掘证明的是研究流程和隔离机制可用，不证明候选具有可交易 Alpha。
